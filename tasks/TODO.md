## Правила работы (важно)

- Одно конкретное предложение прозой, без опросников. Короткие ответы.
- **Approval per-file** — не переносить паттерн с тарифа на тариф без «ок».
- **«Аккуратненько»:** бэкап + синтаксис-чек inline-JS (`node vm.Script`) ДО коммита.
  Паттерн: правка pro → чек → ретест Игорем на живом → перенос в pro-expert/elite.
- **Деплой:** HTML → GitHub Pages (`git push`, домен **via-l.com**); воркер →
  `cd interpreter && wrangler deploy`. Секреты — `wrangler secret put` (репо публичный).
- Папки `Infa Cloude/N-*` — провенанс (gitignore), не коммитить.
