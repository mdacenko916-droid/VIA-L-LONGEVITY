## 0.5 VIO ИИ-воркер — RC1 ЗАМОРОЖЕН (2026-07-11); RC2-бэклог

**Тег `RC1` = commit `2c0dd8f`.** Compliance-гейт закрыт и гарантирован детерминированно (травы убраны ВЕЩЕСТВОМ через `_stripHerbLines`, не переодеты; каузальность/диагноз-рамка/дисклеймеры; хард-баны). Слои: промпт → guardrail (regex→self-check→regen) → детерм. скраб. **Заморожены: `temperature` (0.35), `AI_SAFETY_RULES`, `FEW_SHOT_SAFE`, guardrail, scrub.** Менять только реальные дефекты, не оптимизировать.

**⚖️ ПРАВИЛО САМО-ТРИАЖА остаточных дефектов (важно для будущих правок воркера):**
- **Дезинформация** (фактически ложь, напр. было «мелатонин → внутренний баланс сна») → **БЛОКЕР, чинить всегда**, даже пост-фриз hotfix'ом.
- **Просто коряво, но не ложь** (напр. «из-за естественные изменения», падежи) → **RC2-полировка, фриз НЕ держит.**

**🔒 АНТИ-РЕГРЕСС (не забыть через полгода — почему написан каждый scrubber):**
- **НИКОГДА не ослаблять детерминированный слой** (`_stripHerbLines`, `wellnessHardScrub`, scrub-правила) **ради «более естественного» текста.** Конфликт естественность ↔ compliance → приоритет ВСЕГДА у compliance. Каждое правило скраба стоит на реальной утечке (травы/гормон/приливы), а не на косметике — не «упрощать» его, не поняв why.
- **Зелёный мех-скан ≠ «всё ок» в проде.** Дезинформация без бан-слов проходит молча — это буквально урок треда («мелатонин → внутренний баланс сна»: бан-слов нет, мех-скан зелёный, а утверждение ложно). Поэтому **периодический спот-чек живого вывода ГЛАЗАМИ** (особенно EXPERT/ELITE, где ставки выше) остаётся В ПРОЦЕССЕ — фриз его НЕ закрывает.
- **Латентность «не трогаем» — это ПРЕДПОЛОЖЕНИЕ, пока regen% не снят из прод-логов** (см. бэклог). До цифры решение эмпирикой не подтверждено.

## Правила работы (важно)

- Одно конкретное предложение прозой, без опросников. Короткие ответы.
- **Approval per-file** — не переносить паттерн с тарифа на тариф без «ок».

  Паттерн: правка pro → чек → ретест Игорем на живом → перенос в pro-expert/elite.
- **Деплой:** HTML → GitHub Pages (`git push`, домен **via-l.com**); воркер →
  `cd interpreter && wrangler deploy`. Секреты — `wrangler secret put` (репо публичный).
