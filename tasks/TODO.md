## 2.5. Платформа для многих специалистов ← СЛЕДУЮЩИЙ БОЛЬШОЙ

**Спека на согласовании с владельцем (2026-06-06, уточнена) → [`docs/PLATFORM-MODEL.md`](../docs/PLATFORM-MODEL.md).**
ИП как инструмент для смежных специалистов (гинеколог/эндокринолог/андролог вокруг
пред-менопаузы/андропаузы): специалист рекомендует гаджет → клиент берёт **месячную подписку
PRO** → специалист ведёт его из кабинета (биометрия + ИИ-разборы). Живой эксперт = его врач;
**EXPERT/ELITE остаются воронкой основателя.** Монетизация: клиент платит подписку, специалист —
**абонентскую плату за доступ к платформе.** Принцип — готовое не ломаем: текущий нутрициолог =
«специалист №1».

Ключевое изменение правила: **PRO теперь заводит карточку**, если клиент пришёл по рефералу
специалиста (`ref_code`) → привязка `clients.specialist_id`. Сущности: `specialists`
(+`access_status`/`ref_code`/`lang`) + колонка `specialist_id` у клиента + мост перевода.

Этапы (спека §8): ✅ 1 фундамент → ✅ 2 подключение пациента (`/specialist/connect|unlink`) →
✅ 3 вход+видимость (логин PBKDF2, сессия {id,role}, 403) → ✅ 4 абонплата
(`/specialist-access-webhook` Hotmart + cron-истечение + email специалиста) → ✅ 5 мост перевода
(`/cabinet/translate`, ИИ-черновик на языке специалиста, авто-перевод при отправке, кнопки
«Перевести») → ✅ 6 панель владельца (`/cabinet/specialists|*`, вид «🩺 Специалисты»).

## 4. Hotmart — юридическая упаковка EXPERT/ELITE (EU MDR / FTC / FDA) 🔴 критично

> Владелец 2026-07-02: увод EXPERT/ELITE на Hotmart НЕ защищает от регуляторов ЕС/США.
> Hotmart не модерирует тексты строго, НО: **FTC** штрафует за «Health Claims» (обещания при
> цистите/остеопорозе/геморрое требуют клиники уровня фармы); **FDA** может признать софт
> «незарегистрированным медизделием» (SaMD); **EU MDR 2017/745** — любой продукт, заявляющий, что
> «диагностирует/предотвращает/лечит» болезнь, автоматически под медрегулирование; **сам Hotmart**
> (General Policy 4.11) банит продукты-«альтернативу медпомощи»/обещания излечения → по жалобе из
> ЕС/США мгновенная блокировка аккаунта + заморозка баланса. Глубокий контент резать НЕ надо —
> переупаковать «мы лечим болезни» → «учим управлять телом/биоритмами/образом жизни».

- **Approval per-file** — не переносить паттерн с тарифа на тариф без «ок».

  `cd interpreter && wrangler deploy`. Секреты — `wrangler secret put` (репо публичный).
