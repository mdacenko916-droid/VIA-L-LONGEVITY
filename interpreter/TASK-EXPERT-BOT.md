# Задача: Telegram-бот «Backstage» для тарифа PRO-EXPERT

> **Статус:** запланировано (после реализации счётчика 2 PDF / 30 дней).
> **Тариф:** PRO-EXPERT (€79/мес).
> **Цель:** AI готовит черновик персонального разбора для каждого Expert-запроса; нутрициолог утверждает/редактирует его в Telegram-боте; клиент получает финальный PDF на email.

---

## 1. Принцип

Клиент PRO-EXPERT отправляет запрос через форму в `interpreter-pro-expert.html` (`#maxQuestion` + кнопка «Надіслати запит нутриціологу →»).

После этого:

1. **Apps Script** принимает запрос, валидирует код, проверяет счётчик 2/30, записывает дату в Google Sheet (как сейчас).
2. **Apps Script** передаёт полный пакет данных клиента (биометрия + симптомы + вопрос) в **Cloudflare Worker**.
3. **Cloudflare Worker** запрашивает у Claude API черновик разбора (использует те же 25 паттернов KB, что и `analyze`-эндпоинт, но в более развёрнутом формате — 1500–2000 слов вместо 400).
4. Worker отправляет черновик в **Telegram-бот** через Bot API → бот пишет нутрициологу в личку с кнопками `✅ Утвердить и отправить` / `✏️ Редактировать` / `❌ Отклонить`.
5. Нутрициолог в Telegram редактирует/утверждает → бот рендерит **PDF** (jsPDF или Google Docs API) → отправляет файл клиенту email-ом через **Gmail API**.
6. Клиент получает email с PDF-вложением в течение 48 ч.

## 2. Схема потока данных

```
   ┌──────────────────────────────────────────────────────────────────┐
   │  Клиент PRO-EXPERT                                                │
   │  interpreter-pro-expert.html → форма #maxQuestion                 │
   └────────────────────────────────┬─────────────────────────────────┘
                                    │ POST { code, data, question, email, lang }
                                    ▼
   ┌──────────────────────────────────────────────────────────────────┐
   │  Apps Script (Google)                                             │
   │  • валидация кода                                                 │
   │  • проверка счётчика 2/30                                         │
   │  • запись даты в Sheet                                            │
   │  • forward → Cloudflare Worker /draft endpoint                    │
   └────────────────────────────────┬─────────────────────────────────┘
                                    ▼
   ┌──────────────────────────────────────────────────────────────────┐
   │  Cloudflare Worker /draft                                         │
   │  • Claude API → черновик 1500–2000 слов (KB 25 паттернов)        │
   │  • POST в Telegram Bot API: sendMessage с inline_keyboard        │
   └────────────────────────────────┬─────────────────────────────────┘
                                    ▼
   ┌──────────────────────────────────────────────────────────────────┐
   │  Telegram-бот @viael_backstage_bot (только для нутрициолога)     │
   │  • получает черновик + кнопки [✅ Утвердить] [✏️ Редактировать]  │
   │    [❌ Отклонить]                                                 │
   │  • нутрициолог правит текст прямо в боте (или присылает свою     │
   │    версию)                                                        │
   │  • при «✅ Утвердить» → callback → Worker /finalize                │
   └────────────────────────────────┬─────────────────────────────────┘
                                    ▼
   ┌──────────────────────────────────────────────────────────────────┐
   │  Cloudflare Worker /finalize                                      │
   │  • рендер PDF (jsPDF / pdf-lib / Google Docs Template)            │
   │  • Gmail API: отправка PDF клиенту на email                       │
   │  • запись в Sheet «отправлено» + ссылка на PDF                   │
   └──────────────────────────────────────────────────────────────────┘
```

## 3. Что нужно завести (инфраструктура)

| Компонент | Действие |
|---|---|
| Telegram-бот | Создать в `@BotFather` → получить `BOT_TOKEN` |
| chat_id нутрициолога | Нутрициолог пишет `/start` боту → бот сохраняет `chat_id` |
| Cloudflare Worker | Новые эндпоинты `/draft` и `/finalize` |
| Secrets в Worker | `TELEGRAM_BOT_TOKEN`, `NUTRITIONIST_CHAT_ID`, `GMAIL_OAUTH_TOKEN` |
| Gmail API | OAuth setup для отправки от имени `viaelcom@gmail.com` |
| PDF-шаблон | Дизайн A4: шапка VIA-L · скор · биометрия · разбор · добавки · подпись |
| Google Sheet | Доп. колонки G (used_count_array), H (last_draft_id), I (last_pdf_url) |

## 4. Этапы реализации (по очерёдности)

1. **Скелет**: создать бота, сохранить chat_id, подтвердить что Worker → Telegram → нутрициолог работает.
2. **Draft endpoint**: Worker принимает данные клиента, дёргает Claude, шлёт текст в Telegram.
3. **Inline-keyboard**: добавить кнопки `Утвердить / Редактировать / Отклонить`, обработка callback'ов.
4. **PDF-рендер**: выбрать библиотеку (рекомендую `pdf-lib` — работает в Worker без npm-зависимостей), сделать шаблон.
5. **Gmail-отправка**: OAuth, шаблон письма, прикрепление PDF.
6. **Логирование**: запись результата в Sheet, retry при ошибках.

---

## 5. Открытые вопросы (решить перед стартом)

- **PDF-шаблон**: дизайн нужно сверстать. Использовать существующий `downloadPDF()` HTML/print или новый макет.
- **Редактирование в Telegram**: бот принимает правки одним сообщением (clear-and-replace) или поддерживает inline-комментарии? Проще — clear-and-replace.
- **Хранение PDF**: только email-вложение или ещё ссылка в Google Drive / R2?
- **Если нутрициолог не утвердил за 48 ч**: автоматический фолбек (отправить AI-черновик «как есть»? отказать клиенту с возвратом запроса в счётчик?).
- **Подпись нутрициолога**: статичный SVG/PNG в PDF или поле «От: имя» текстом?

## 6. Связка с другими тарифами

- **ELITE** Telegram (`t.me/Viaelcomlongvity`) — это **личный аккаунт** нутрициолога, видим клиенту. Не путать с этим ботом.
- **EXPERT** бот (`@viael_backstage_bot`) — **backstage**, клиент его не видит и не знает о его существовании.

В клиенте Telegram у нутрициолога будут две независимые вкладки: личка с ELITE-клиентами + поток черновиков из бота с EXPERT-клиентами.
