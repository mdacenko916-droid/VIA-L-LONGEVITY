# Задача: Onboarding-анкета для ELITE-клиентов

> **Статус:** запланировано (после завершения Telegram-бота этапов 3–7).
> **Тариф:** только ELITE-8W и ELITE-12W (для EXPERT не нужно — там просто еженедельные отчёты).
> **Цель:** после оплаты ELITE клиент сначала заполняет начальную анкету-анамнез; ответы попадают нутрициологу для составления персонального протокола до старта программы.

---

## 1. Принцип потока

```
Клиент → Hotmart (ELITE-8W или ELITE-12W) → оплата → код доступа на email
   ↓
Первый вход в interpreter-elite.html → gate → код принят
   ↓
Apps Script проверяет: было ли пройдено onboarding для этого кода?
   • НЕТ → редирект на elite-onboarding.html
   • ДА  → обычный финал ELITE (16 шагов + отчёты)
   ↓
Клиент заполняет анкету (10–15 вопросов)
   ↓
POST в Apps Script:
   • email с анкетой → viaelcom@gmail.com (нутрициологу)
   • карточка в backstage-бот → @viael_backstage_bot
   • статус «onboarded» в Google Sheet (новая колонка G)
   ↓
Нутрициолог получает анкету → составляет персональный план → отвечает клиенту
   ↓
Клиент возвращается в interpreter-elite.html → доступ к 16 шагам и еженедельным отчётам
```

---

## 2. Содержание анкеты (черновик — уточнить с нутрициологом)

**Базовые данные:**
- Имя, возраст, рост, вес, страна
- Контакт: email, Telegram, телефон (опционально)
- Предпочтительное время для созвонов (часовой пояс)

**Цели программы:**
- Что хочется получить в первую очередь (выбор + свободный текст)
- На какой результат рассчитываете через 8 / 12 недель
- Что пробовали раньше, что не сработало

**Здоровье (анамнез):**
- Хронические заболевания
- Текущие медикаменты + дозировки
- Аллергии
- Последние анализы (PDF / фото / нет)
- У женщин: фаза (цикл / перименопауза / менопауза / постменопауза), дата последней менструации, ГЗТ
- У мужчин: симптомы андропаузы, тестостерон-замещающая терапия

**Образ жизни:**
- Сон (часов, качество, проблемы)
- Питание (типичный день, исключения, режим)
- Физическая активность (типы, частота)
- Стресс (уровень, источники)
- Алкоголь, кофеин, никотин

**Добавки:**
- Что принимаете сейчас (название + доза + давно ли)

**Трекер:**
- Какой носите (Oura / Apple Watch / Garmin / нет)
- Готовы ли давать API-доступ

## 3. Где разместить анкету

Вариант A — **отдельная страница** `interpreter/elite-onboarding.html`:
- Мультиязычно (12 языков ИП, ru/uk/es/en точно нужны).
- Дизайн в стиле остальных страниц ИП (золото на тёмном).
- Прогресс-бар по секциям.
- POST в Apps Script через `action=elite_onboarding`.
- **Плюсы:** полный контроль, единый стиль, привязка к коду доступа.
- **Минусы:** надо верстать, поддерживать i18n.

Вариант B — **Google Forms**:
- Быстрый MVP, готовые ответы в Sheet.
- **Минусы:** дизайн не совпадает с ИП, нет привязки к коду доступа клиента.

**Рекомендую A** — на одном уровне с остальной системой.

---

## 4. Изменения в Google Sheet

Добавить колонку **G: Onboarding** — JSON `{ "completed_at": "ISO", "data": {...} }` или null.

Логика на сервере:
- При валидации ELITE-кода (`validateCode`): если `G` пустой → возвращать `{ ok: true, onboarding_required: true, ... }`.
- Клиент: если `onboarding_required=true` → редирект на `elite-onboarding.html`.
- После заполнения: `action=elite_onboarding` → запись в G + email + бот.

## 5. Интеграция с backstage-ботом

После заполнения анкеты — отдельная карточка в Telegram у нутрициолога:

```
🧬 ELITE Onboarding · Анна Иванова
Программа: ELITE-12W (12 недель)
Email: anna@example.com · Telegram: @anna_i
Фаза: перименопауза · возраст 48
Цели: нормализовать сон, снизить тревожность
[Открыть полную анкету →]  ← ссылка на просмотр в Apps Script
```

Кнопка `[Открыть полную анкету →]` ведёт на временную HTML-страницу в Apps Script (или Google Doc с автогенерацией).

---

## 6. Этапы реализации

1. **Скелет страницы** `elite-onboarding.html` (ru/uk, остальные языки потом).
2. **Apps Script**: новый action `elite_onboarding` → запись в G, email, бот.
3. **Gate-логика**: при первом входе ELITE-кода → редирект на onboarding.
4. **Карточка в бот**: формат + кнопка «Полная анкета».
5. **i18n**: разворачивание на 12 языков.
