# art/ — картинки VIA-L (2026-10-27)

- `bg-home.webp` — фото первого и ежедневного экрана VIA-L (2026-11-10, вместо силуэтов), 941×1672; исходник —
  `скрин/м/Марина  VIA-L.PNG`. Раскладка как в ADAM-L: картинка шире экрана и прижата влево, лицо уходит к правому краю.
  Новую картинку класть с тем же именем; лицо — справа от центра, левая треть — тёмная (там знак и заголовок).
- `bg-app.webp` — общий фон VIA-L на всех остальных экранах (2026-11-10, вместо графита), 854×1840, золотые ленты
  без лица; исходник — `скрин/м/Фон Марина.png`. Подключён через `--app-bg` в interpreter-via-l.html (холст, «Профиль»,
  «Мой прогресс», «Специалист», «Библиотека»). ADAM-L не затронут.
- `silhouettes.webp` — (не используется с 2026-11-10) золотые силуэты для первого и ежедневного экрана, PNG-исходник на чёрном фоне;
  чёрный переведён в прозрачность по яркости (наложение screen не работает: .hero — свой слой z-index).
- `lib/<тема>.jpg` — по одной картинке на тему Библиотеки VIA-L, 1200×600. Имя = ключ темы из
  `library.js` (TOPIC) без префикса `m_`: мужские общие темы (m_sleep, m_heart, m_sex, m_exercise,
  m_checks) берут те же картинки; `myths.jpg` — и для `myths`, и для `m_myths`; `stress.jpg` — для `m_stress`.
- Исходники PNG лежат у владельца в `скрин/1/3/`. Новую картинку класть с тем же именем — код не меняется.
- `move/<состояние>.jpg` — фото карточки «Нагрузка на сегодня» (2026-10-31), 1200×600: green (хороший день), yellow,
  red, rest, pain, ill, bp, limit, sport — по причине выбора тренировки (`PH` в `tools/workouts/wo_logic.js`).
  Женская серия (VIA-L). `move-m/` — мужская серия с теми же именами, ADAM-L ставит `window.VIAL_MOVE_ART='art/move-m/'`.
