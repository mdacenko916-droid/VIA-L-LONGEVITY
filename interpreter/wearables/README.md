## Что значат слова (простым языком)

- **Коды (Client ID + Client Secret)** — это логин и пароль *нашего приложения* у вендора.
  Вендор выдаёт их, когда мы регистрируем у него приложение. Без них сайт не имеет права
  забирать данные. Client ID можно показывать, Client Secret — секретный, прячем на сервере.
- **OAuth** — способ, которым клиент нажимает «Подключить» и сам разрешает нашему сайту
  читать его данные. Пароль клиента мы никогда не видим.
- **Воркер (Cloudflare Worker)** — наша серверная программа, которая хранит секреты и
  ходит к вендору за данными. Включается командой `wrangler deploy`.
- **Секрет в воркере** — кладётся командой `wrangler secret put ИМЯ`, в коде не виден.
