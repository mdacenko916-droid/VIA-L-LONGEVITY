# Устройства без веб-доступа: Apple / Samsung / Xiaomi / Amazfit

**Краткий статус:** через **сайт** авто-подключение невозможно (у этих производителей нет
публичного веб-доступа к данным). Зато их **закрывает будущее приложение** для App Store
и Google Play — там подключение нативное. То есть это не тупик, а другой путь.

## Почему через сайт нельзя
- **Apple Watch / Apple Health** — данные живут только на iPhone (HealthKit), облачного
  API нет. Сайт до них не дотянется.
- **Samsung Health** — доступ закрыт партнёрской программой, инструменты только под Android.
- **Xiaomi / Amazfit (Zepp)** — публичного OAuth нет.

## Как их закроет приложение (отдельная задача, другой чат)
- **iPhone (iOS):** приложение читает данные напрямую из **HealthKit** — это и есть
  интеграция Apple Watch (и любых устройств, что пишут в Apple Health).
- **Android:** приложение читает из **Health Connect** — общий «склад» здоровья Android,
  куда сами стекаются **Samsung Health, Xiaomi, Amazfit (Zepp)** и другие. Подключив
  Health Connect, мы разом получаем эти устройства.
- Подробнее про приложение — память `project_mobile_app.md` и `docs/MOBILE-APP-MODEL.md`.

## Что делать сейчас (пока приложения нет)
- На сайте у этих карточек оставить вкладку «Ввести вручную» / «Дополнить данные».
- Если у клиента есть устройство из «готового» списка (Fitbit/Polar/Withings/…) — лучше
  подключить его.

## Запасной общий путь (на будущее, для веб-части)
- Агрегаторы носимых (Terra, Spike, Rook, Validic) дают **один** доступ сразу ко многим
  устройствам. Платно. Рассмотреть, если понадобится широкое покрытие до выхода приложения.
