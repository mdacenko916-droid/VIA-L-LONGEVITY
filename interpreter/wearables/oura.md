# Oura (кольцо)

**Краткий статус:** почти готово. Не хватает только кодов от Oura. Получить их можно
самому, бесплатно — нужен лишь аккаунт Oura (появится с кольцом жены).

## Сейчас (как есть)
- В тарифе **VIO** работает демо-режим: кнопка «✨ Загрузить демо-данные» подставляет
  примерные цифры (не настоящие данные клиента). Это нормально для бесплатного тарифа.
- В **PRO / ELITE** есть старая кнопка «вставить токен» — **она больше не работает**:
  Oura удалил Personal Access Tokens в декабре 2025. Инструкцию «создать токен» мы всё
  ещё показываем клиентам на 12 языках — её нужно убрать (вводит в заблуждение).

## Что нужно сделать
1. **Владелец:** после появления аккаунта зайти на `cloud.ouraring.com/oauth/applications`,
   создать приложение. Адрес возврата (redirect URI) вписать:
   `https://interpreter.viaelcom.workers.dev/oura/callback`.
2. **Владелец:** прислать мне **Client ID** (открыто), а **Client Secret** заложить командой
   `wrangler secret put OURA_CLIENT_ID` и `wrangler secret put OURA_CLIENT_SECRET`.
3. **Я:** написать в воркере три адреса `/oura/start`, `/oura/callback`, `/oura/metrics`
   (по образцу Fitbit/WHOOP) и кнопку «🔗 Подключить кольцо» во всех трёх платных тарифах.
4. **Я:** убрать устаревшие инструкции про Personal Access Token (12 языков).
5. `wrangler deploy` — и Oura включён.

## Важно знать
- Регистрация приложения **бесплатна и делается самим**, без ожидания вендора.
- У нового приложения лимит **10 клиентов**. Этого хватит на старт и обкатку. Когда
  клиентов станет больше — на странице приложения жмём «отправить на проверку»
  (submit for review) — это и есть тот самый «партнёрский» шаг, только теперь по делу.
- Данные приходят **от каждого клиента** (его кольцо + его активная подписка Oura),
  а не от нашего/жениного кольца. Наш аккаунт нужен только чтобы создать приложение.
- Клиенты Gen3 / Ring 4 без активной подписки Oura данные через API не отдают.
