# Сборка `interpreter/workouts.js` («Тренировка дня»)

`python3 tools/workouts/gen_wo.py` — пересобирает файл целиком.

- `workouts_ru.json` — 30 тренировок, разобранные из `docs/FITNESS-WORKOUTS.md` (части, круги, упражнения, дозы по-русски).
- `names.json` — 199 уникальных названий упражнений (порядок = индекс); `tr_*.py` — переводы ×11 в том же порядке,
  `tr_extra.py` — 15 названий дыхательных разминок + к каким тренировкам они относятся;
  `tr_v2.py` — каталог v2 (2026-10-08): замены названий по индексу + 18 новых для №16/№17 и Otago (сами №16/№17 — в `gen_wo.py`).
- `tr_ui.py` — названия тренировок, уровни, инвентарь, части, единицы доз, тексты карточки и «почему» ×12.
- `wo_logic.js` — выбор, отрисовка, журнал «Сделано» (дописывается в конец файла как есть).

Поменяли план в `FITNESS-WORKOUTS.md` → поправить `workouts_ru.json` (новое название — в конец `names.json`
и во все `tr_*.py`), пересобрать, проверить на 3–4 языках.
