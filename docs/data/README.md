## exercise-db-home.json
277 упражнений из [yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Unlicense,
общественное достояние) — отобраны те, что делаются дома: **без инвентаря, с гантелями, резинками,
фитболом и валиком**; залового (штанга, тросы, тренажёры) здесь нет. Поля: название, сложность,
инвентарь, основные и вспомогательные мышцы, пошаговая инструкция (EN), категория.

**Взяты только тексты.** Фотографии этой базы НЕ копируем: лицензия Unlicense покрывает данные,
а снимки пришли из чужой коммерческой фотосъёмки (через `wrkout/exercises.json`) и прав на них нет.

**Зачем:** справочник при составлении и переводе планов, подсказки по мышцам и инвентарю для карточек
упражнений. Наши собственные планы — `docs/FITNESS-WORKOUTS.md`, список для съёмки —
`docs/FITNESS-EXERCISE-LIST.md`.
