# Подбор вида активности — ходьба, бег, велосипед, плавание, силовая, пилатес…

> Начато 2026-10-07. **Зачем:** VIA-L сейчас решает «силовая / кардио / лёгкий день / отдых» (`selectExercisePlan`,
> `_todayMovePlan` в воркере), но не говорит, **чем именно** заняться. Человеку нужно конкретное: «сегодня —
> скандинавская ходьба 40 минут» или «бассейн вместо бега: колени».
> **Принцип:** выбирает КОД из того, что человеку **доступно и в радость**, с учётом состояния дня и ограничений;
> модель только объясняет «почему». Опирается на светофор и правила [`FITNESS-SELECTION-RULES.md`](FITNESS-SELECTION-RULES.md).
> Сырьё PubMed — `interpreter/Infa Cloude/FIZ/pubmed/PM-ACT.txt` (14 обзоров, PMID сверены).

## 1. Вопрос в профиль (разово, можно менять)

«Что вам доступно и в радость?» — несколько отметок:

| Ключ | Вид |
|---|---|
| `walk` | Ходьба |
| `nordic` | Скандинавская ходьба |
| `run` | Бег |
| `bike` | Велосипед / велотренажёр |
| `swim` | Плавание, аквааэробика |
| `str_home` | Силовая дома (гантели, резина, вес тела) |
| `str_gym` | Силовая в зале |
| `pilates` | Пилатес |
| `yoga` | Йога |
| `dance` | Танцы |

Ничего не отмечено → по умолчанию `walk` + `str_home` (доступны всем).

## 2. Что даёт каждый вид — по доказательствам

| Вид | Кости | Суставы | Тазовое дно | Давление, сердце | Симптомы перехода | Источник |
|---|---|---|---|---|---|---|
| Ходьба | шейка бедра — только при >6 мес; позвоночник — нет | щадит | безопасно | **снижает верхнее давление** (Cochrane 2021, 73 РКИ) | — | 24149921; 33630309 |
| Скандинавская ходьба | как ходьба | щадит, руки в работе | безопасно | **лучше быстрой ходьбы** по пульсу, давлению, VO₂, качеству жизни | — | 23253654 |
| Бег | удар есть, но после менопаузы удар сам по себе слаб | любительский бег **не повышает** артроз (у любителей ниже, чем у сидячих) | **ударная нагрузка — чаще подтекание** | хорошо для сердца | — | 28504066; 29552736 |
| Велосипед | **не укрепляет** (шоссе — ниже плотность) | щадит колени | — | хорошо; после менопаузы интервалы на велосипеде эффективнее бега для жира | — | 23256921; 32613697 |
| Плавание, аквааэробика | **не укрепляет** (как у сидячих); вода-упражнения — немного лучше покоя, хуже суши | **при артрозе: меньше боли** (Cochrane 2016) | безопасно | **снижает давление**, и не только плавание | — | 28394711; 28392717; 27007113; 28914562 |
| Силовая (дом / зал) | **основа для кости** вместе с ударом | адаптировать, не отменять | дыхание без задержки | снижает давление | **приливы −44%** (одно РКИ) | см. `FITNESS-WOMEN-EVIDENCE.md` |
| Пилатес | **не укрепляет** | — | = тренировка тазового дна, если сознательно сокращать | — | — | 33967223; 38206341 |
| Пилатес (спина) | — | **одна из самых действенных при боли в спине** | — | — | — | 34538747; 26133923 |
| Йога | — | — | — | — | **симптомы перехода −1,05, приливы −0,76** (против без лечения), как другие упражнения | 29452777 |
| Танцы | — | — | прыжковые — как удар | — | баланс, походка — польза, данные слабые | 25456888 |

Общее правило из сетевого мета-анализа по спине (34538747): **человеку стоит делать то, что ему нравится** —
это держит регулярность. Поэтому «в радость» — полноправный критерий выбора, а не украшение.

## 3. Правила выбора (код)

**Шаг 1. Тип дня** — уже решает воркер: `нет тренировки` (давление §10) · `отдых` · `лёгкий` · `кардио` · `силовая`.

**Шаг 2. Кандидаты** = отмеченные виды, подходящие типу дня:

| Тип дня | Подходят |
|---|---|
| нет тренировки | ничего (бытовые дела) |
| отдых | прогулка спокойно (`walk`) — по желанию |
| лёгкий | `walk`, `yoga`, `pilates` (мягко), `swim` спокойно |
| кардио | `nordic`, `walk` быстро, `bike`, `swim`, `run`, `dance` |
| силовая | `str_gym` / `str_home`; `pilates` — добавкой для корпуса, не вместо |

**Шаг 3. Ограничения убирают или сдвигают:**

| Состояние | Убрать | Предпочесть |
|---|---|---|
| Артроз колена/бедра, ИМТ ≥ 30 | бег — не начинать с нуля (если уже бегает без боли — можно) | `swim`, `bike`, `nordic` |
| Подтекание, тяжесть | `run`, прыжковые `dance` (до лестницы §13) | `walk`, `nordic`, `swim`, `bike`, `pilates` с тазовым дном |
| Остеопороз / цель «кости» | — (ничего не запрещаем) | но `swim`, `bike`, `pilates`, `yoga` **не засчитываем как костную нагрузку** — силовая 2 раза + удар обязательны |
| Боль в спине | осевая нагрузка с весом | `pilates` |
| Гипертензия | максимальные усилия, задержка дыхания | `walk`, `nordic`, `swim`, `bike` умеренно; изометрия можно |
| Давление выше своей нормы сегодня | всё | — (§10) |

**Шаг 4. Жалоба выбирает из оставшихся** (при равенстве):

| Жалоба | Предпочесть |
|---|---|
| Приливы | силовая; `yoga` как добавка; прохладная среда (бассейн) — ⏳ доказательства |
| Настроение, тревога | `yoga`, `dance`, `nordic` на улице |
| Сон | умеренное кардио днём (`walk`, `nordic`, `swim`); не интенсивно за час до сна |
| Живот, вес | силовая + `bike` (интервалы после менопаузы на велосипеде эффективнее бега) |
| Суставы | `swim`, `bike`, `nordic` |
| Спина | `pilates` |
| Падения, баланс, 60+ | `dance`, `nordic`, баланс в каждой тренировке |

**Шаг 5. Из оставшихся — что человек делал реже на этой неделе** (разнообразие), при равенстве — первое
отмеченное «в радость». Длительность и интенсивность — из рамки движения (разговорный тест, 150 мин/нед и т. п.).

**Что пишет ИИ:** одна-две фразы «почему именно это сегодня», словами клиента, без диагнозов. Например:
«Сегодня — бассейн 30–40 минут: вчера была силовая на ноги, а колени лучше переносят воду, чем бег».

## 4. Пробелы → вопросы к OpenEvidence

PubMed не ответил прямо на эти — см. блок вопросов ниже (файлы `FIZ/QA1.txt` … `QA6.txt`).

1. **QA1** — прохладная среда (бассейн) и приливы; провоцирует ли жара или интенсивность приливы во время занятий.
2. **QA2** — велосипед и тазовое дно / промежность у женщин 40+ (давление седла, онемение) — ограничения.
3. **QA3** — сравнение видов кардио для женщин 40–65: ходьба, скандинавская, велосипед, плавание, бег — VO₂max,
   давление, жир живота, переносимость.
4. **QA4** — как начать бегать в 40–65 без опыта: схема «ходьба–бег», травмы, кому не начинать.
5. **QA5** — йога, пилатес, тайцзи против аэробных для сна и тревоги в перименопаузе.
6. **QA6** — плавание и вода при остеопорозе: роль (не для кости, но для чего) и сочетание с силовой.
