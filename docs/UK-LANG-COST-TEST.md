## B. Дешевий шлях: Haiku російською + переклад українською

**Де ви зараз**

Припливи самі по собі легкі, але вони розривають ніч, а це каскадом впливає на все інше.

**Загальна картина**
Ваші дані малюють єдиний ланцюг: ніч рвана через припливи → сон короткий та неглибокий (6,2 год при нормі 7–9) → енергія вдень падає (4/10) → вечорі тягне на солодке (це реакція тіла на недосип та стрибки цукру) → пульс спокою трохи вище звичайного (72 уд/хв), тривога підвищена (6/10).
