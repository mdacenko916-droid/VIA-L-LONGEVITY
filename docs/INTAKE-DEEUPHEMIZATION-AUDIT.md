> **Дата: 2026-07-11.** Продолжение reframe'а воркера (см. [`AI-ANALYZER-TEXT-RULES.md`](AI-ANALYZER-TEXT-RULES.md)).

## Класс В — НЕ трогать

- **value-ID бандла** (`cycle_factor`, `gi_heaviness`, `core_tone`…) — остаются нейтральными: сканер читает строки бандла; воркер `has()` принимает старые+новые. Меняем ТОЛЬКО видимый текст.
- **Claim-части `_wl`**: срез доз/KSM-66 у гормональных трав, скобочные code-tokens, drug-interaction фразы — это claim-guards, работают.
- Дисклеймеры, «обсудите со специалистом» — на месте.

## Сопутствующие дефекты Памятки дня (из прогона Кати)

1. Заголовок «Нутрицевтики (утро/вечер)» — запрещён нашим же правилом → «Если принимаете добавки (утро/вечер)». Источник: `/day-plan` промпт или `_bpChapterData`.
2. Битый пункт «–Сразу я на 10–15 минут» (обрезано, известный §4-дефект RC2-брифа) — воспроизвёлся, диагностировать `_cleanPlan`/обрыв.
3. «Поведенческие ориентиры вечера» → глагольный заголовок («Подготовьтесь ко сну»).
4. NB: Памятка кэшируется 1×/день (`vial_day_plan`) — при тестах чистить кэш.

## Порядок работ

1. ✅ Аудит (этот файл) → **владелец утверждает формулировки, особенно класс Б**.
2. `_wl`: ретайр term-правил (RU+EN+все языки — правила мультиязычны по строкам, ретайр = удаление строк), keep claim-правил.
3. Лейблы опросника RU+EN (обе i18n-системы + строка 2687) — по утверждённой таблице.
4. Визуальный тест владельцем (опросник + живой разбор: падежи «приливов» здоровые, ВСР виден).
5. Остальные 10 языков (лейблы) + Памятка (заголовки, битый пункт).
6. PRO-зеркало (паритет) — отдельным заходом.
