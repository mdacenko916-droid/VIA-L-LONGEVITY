# Перестройка тарифов ИП — план и цель

Статус на 2026-06-19. Этот документ — точка входа для продолжения работы по выравниванию
тарифов ИП под новый **PRO**. Связано: `interpreter/interpreter-*.html`,
`docs/TARIFF-DATA-SOURCE-MODEL.md`, память `project-tariff-design-divergence`,
`project-pro-funnel-structure`.

## К чему идём (конечная цель)

Все 4 инструмента ИП — **в едином стиле и структуре нового PRO**, но каждый со своим
**цветом-акцентом** и своей **тарифной спецификой**. Эталон структуры/UX — `interpreter-pro.html`
(пересобран 2026-06-18: каденс блоков, заголовки-группы, редизайн приливов/когниции/ПМС/
тревожности, гаджет-панель, заголовки, мобайл, золото на тёмном).

## Файлы и идентичность тарифов

4 отдельных HTML (~950КБ; vio ~667КБ) в `interpreter/`. Это **не общий файл** — копии,
исторически сильно разошедшиеся (авто-патч pro→тариф не ложится: 11/54 хунка). У каждого свой
`<title>`, `DEV_CODES`, цены/CTA. Гейт фич — `vial_access==='MAX'` (одинаков в pro/expert).

## Метод (как переносить, по уму)

**Дизайн (безопасно, сделано):** аддитивный CSS-override в конце `<style>` в цвет тарифа
(карточки `.step>.card` + border + glow + halo off, `.card-accent/::before`, бейдж/деск, чипы,
`.manual-input`, `.topbar-home`, модал `.gate-*`). Палитры — из тарифных карточек `index.html`.

**Чистый структурный порт (блок == pro-old по структуре + движок совместим):**
рецепт — добавить i18n-мердж-блок после строки `['ru'..].forEach(T[l]=Object.assign({},T.en,T[l]))`,
заменить разметку шага, поправить data-build. ОБЯЗАТЕЛЬНО: синтаксис-чек inline-JS + проверка,
что движок (ветки оценки) читает те же значения.

**Нечистый порт (блок структурно ДРУГОЙ в тарифе) — НЕ форсить наскоком:** требует переписать
движок живой платной страницы = риск. Только осознанным продуктовым решением + тест.

## Статус по блокам (✅ сделано / ⬜ осталось / 🚫 не лёг чисто)

**Дизайн/цвет:** PRO ✅ · EXPERT ✅ · ELITE ✅ · VIO ✅

**Структура:**
- ПМС → 11-пунктовый чеклист (движок выводит тяжесть из числа: 0/1–3/4–6/7+ → none/mild/mod/severe):
  EXPERT ✅ · ELITE ✅ · VIO ✅
- Тревожность → 4 уровня (ползунок 1–10 → 4 радио value 1/4/7/9, getRadio): EXPERT ✅ · ELITE ✅ · VIO 🚫(нет ползунка)
- 🚫 **Когниция** — в тарифах память категориальная (good/slight/poor/severe) + туман 4-уровневый
  (none/morning/daily/constant), движок читает их; в pro — память 1–10 + туман Да/Нет. Унификация =
  переписать `_mapMem`/`_mapFog` и ветки оценки тарифа. **Продуктовое решение.**
- 🚫 **Приливы** — в тарифах доп-поля `hotfreq`/`hf_time` + температура вводится вручную (нет
  гаджет-панели); pro-редизайн «за сутки» со скрытой температурой не ложится. **Продуктовое решение.**
- 🚫 **Самочувствие / Настроение / Раздражительность** — движок тарифа читает symptoms/mood/
  irritability; в pro удалены. Удалять в тарифах = трогать оценку.
- ⬜ **Каденс / заголовки-группы / гаджет-панель / кнопка результата инлайн / мобайл-фиксы** —
  pro-специфика для гаджетного дневного потока; у тарифов другой flow (онбординг). Переносить
  выборочно и осознанно, НЕ механически.
