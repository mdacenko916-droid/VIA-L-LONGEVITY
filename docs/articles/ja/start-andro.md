# 男性更年期(アンドロポーズ):40歳を過ぎた男性に本当に起きていること

*5分で読めます*

力が出ない、おなかが出てきた、性欲が落ち着いてきた。そして広告ではいつも「テストステロン低下」や「男性の更年期」。すべてはひとつのホルモンのせいで、すぐに上げなければならない、と信じたくなります。けれども実際の姿はもっと正直で、幸い、もっと希望が持てるものです。

## 「男性版の閉経」ではありません

女性の閉経は誰にでも、しかもかなりはっきりと訪れます。男性にはそういうものはありません。テストステロンはゆっくりと、人によってさまざまに下がり、健康な男性では70歳ごろまでほとんど下がりません。

中年期に下がるおもな原因は、年齢そのものではなく、体の暮らし方です。おなかまわりの余分な脂肪、糖尿病、睡眠不足や睡眠時無呼吸、慢性的なストレス、一部の薬。だから40〜60歳の男性の多くにとって、「テストステロンが低い」は**機能的で元に戻せる**状態であって、ずっと続く故障ではありません。

## テストステロンは、原因より温度計であることが多い

これがいちばん大切な点です。テストステロンが低いということは、ふつう、体の調子が悪いことを**示して**いるのであって、それ自体が不調を起こしているのではありません。原因に手をつけずに数値だけ上げても、たいてい体調はよくなりません。

テストステロンの低さとはっきり結びついているのは、性に関するサインだけです。朝の勃起が減る、性欲が落ち着く。それでさえ結びつきはゆるやかです。疲れ、気分の落ち込み、頭の「もや」、筋肉の減少では、テストステロンの低さと、睡眠不足、うつ、体重の増えすぎ、甲状腺とをほとんど見分けられません。「テストステロンをチェック」といった質問票は、コイン投げと変わらない精度です。

指輪型や腕時計型のデバイスは、テストステロンを測ることも計算することもできません。脈拍、心拍変動、「コンディション」の値は、睡眠から前の晩の一杯まで、何十もの要因で変わります。回復のサインとして見るもので、「ホルモンの値」ではありません。

## いちばん効く、体を立て直す方法

**ウエスト。** 最も強い手段です。おなかまわりの脂肪はそれ自体がテストステロンを下げ、体重を5〜10%減らすと、テストステロンはおよそそれに比例して上がります。体重計を見るより、ウエストを測るほうが大切です。

**睡眠。** 睡眠不足と睡眠時無呼吸はテストステロンを下げ、それは元に戻せます。無呼吸は40歳以上の男性にとても多く、ほとんどの場合見つかっていません。途切れるような大きないびきと日中の眠気は、睡眠の検査について医師に相談するきっかけになります。

**筋トレ。** 体の組成、気分、性欲をよくします。安静時のテストステロンは上げません。「急上昇」のためではなく、筋力と代謝のために鍛えましょう。

**大量の飲酒を減らす。** ほどほどの飲酒ではテストステロンは下がりませんが、大量の飲酒やどか飲みでは下がります。これも元に戻せます。

いい知らせです。テストステロンの数値があまり動かなくても、代謝を立て直すこと自体で体調と性欲はよくなります。

## 避けたほうがいいもの

- **「テストステロンブースター」。** 効果が証明されたものはほとんどありません。トリビュラス、D-アスパラギン酸、ホウ素、DHEAはテストステロンを上げません。こうした製品の一部には、表示されていない薬が入っています。
- **「テストステロン低下」クリニックやオンライン処方。** 値が正常な男性にもホルモンを処方し、心臓や子どものことを尋ねないことがよくあります。
- **自己判断のテストステロン。** 外から入れるホルモンは、ほとんど男性用の避妊薬のように働きます。精子をつくる働きを、ときには長期間止めてしまいます。まだ子どもを望んでいるなら、なおさら大切です。テストステロンは、朝の検査を2回行い、医師が判断して、不足が確かめられた場合にだけ処方されます。

- **40〜60歳で新しく出てきた勃起の問題。** ホルモンだけでなく、血管と心臓からの早いサインであることがよくあります。詳しくは「40歳を過ぎた性欲と勃起」の記事で。

- ひどく落ち込んだ気分。自分を傷つけたいという考えがあれば、すぐに専門家か、こころの相談窓口へ。
