# 閉経:最後の月経のあとに何が変わるのか

*5分で読めます*

閉経とは、月経が12か月続けてない状態になった時点のことです。その後はすべて閉経後の期間です。エストロゲンはいまや安定して低くなり、体はこの新しい現実に合わせて組み直されていきます。変化の一部はすぐに感じられますが、一部は「静か」で、何年もたってから表に出てきます。後者は前もって知っておく価値があります。閉経後の最初の数年こそ、この先の何十年のためにいちばん多くのことができる時期だからです。

## 感じられること

エストロゲンが少なくなると、よく知られたパターンがそろいます。ホットフラッシュ、寝汗、細切れの睡眠、乾燥や性交時の不快感、関節や筋肉のうずき、頭の「もや」。これはばらばらの悩みの寄せ集めではなく、ひとつの流れです。まとめて向き合うほうがうまくいきます。

乾燥と性交時の不快感について、別にお話しします。これはとてもよくある変化で、女性の半数かそれ以上に起こりますが、ほとんど話題になりません。ホットフラッシュと違って自然には治らず、時間とともに強くなります。そのかわり、助けがよく効きます。保湿剤を定期的に使う、性交時には潤滑剤を使う、骨盤底のトレーニング、そして医師との相談。がまんする必要はありません。

## 感じられないけれど大切なこと

**心臓と血管。** 閉経前の女性の心臓病のリスクは男性のおよそ半分ですが、エストロゲンが下がるとその差は急速に縮まります。いちばん急に進むのは、最後の月経をはさんだ1〜2年です。「悪玉」コレステロールが増え、血管が硬くなります。これは避けられない運命ではなく、予防のための窓です。

**骨。** 骨が最も速く失われるのは、最後の月経のおよそ1年前から2年後までです。背骨では年に最大2%。骨折するまで症状はありません。45歳より前の早い閉経、軽いけがでの骨折、ステロイドの長期使用、親の大腿骨骨折のいずれかがあれば、65歳を待たずに、いまのうちに骨密度検査について医師と相談しておきましょう。

**筋肉と代謝。** 脂肪がおなかへ移り、体は糖への反応が鈍くなり、筋肉はタンパク質や運動への反応が鈍くなります。甘いものへの欲求、頭の「もや」、体型の変化は、ひとつながりです。

## やること

**週2回の筋トレ。** ホットフラッシュ、気分、骨、筋肉、代謝のすべてに一度に効く手段です。基本はスクワット、引く動作、押す動作。痛みのない範囲で。

**朝食から、毎食タンパク質を。** 40歳を過ぎると、筋肉は以前より多くのタンパク質を必要とします。そして朝食は、たいていいちばんタンパク質が少ない食事です。

**食後に歩く。** 食後10〜15分歩くと、体が糖をうまく処理しやすくなります。

**地中海式の食事。** オリーブオイル、魚、ナッツ、野菜、食物繊維。心臓と血管を支える方法として、最もよく研究されています。
