# 35歳を過ぎた周期:多く、間遠く、予測しにくく — 何が起きているのか

*5分で読めます*

月経が3週間で来たかと思えば、2か月来ない。量が多く、長くなり、血のかたまりが出るようになった。夜用のナプキンでも足りない。35〜50歳では、こうした変化はとてもよくあることで、移行期の最初のサインのひとつです。けれども「よくある」は「がまんする」という意味ではありません。

## なぜ周期が変わるのか

移行期には、排卵のない周期がしだいに増え、プロゲステロンが少なくなります。この時期のエストロゲンは下がるのではなく揺れ、ときには普段より高くなります。予測しにくさも、月経の量が増えるのも、そこから来ています。

指輪型や腕時計型のデバイスをつけているなら:排卵後の夜間の体温の上昇は、後になってからとらえられます。その周期に上昇がなかったからといって「プロゲステロンが少ない」わけではありません。40歳を過ぎると、排卵のない周期もただあるのです。

## 「多い」の目安

多い月経は「私の体質」と思われがちで、何年も調べられないままになります。目安は:

- ナプキンやタンポンを**数時間続けて1時間ごとに**替えなければならない。
- 硬貨より大きな血のかたまり。
- もれてしまい、「二重の対策」が必要。
- 月経が7日より長く続く。
- 出血のせいで、ふだんの1日が制限される。

## 多い月経と鉄

多い月経は、女性の鉄不足の最もよくある原因です。鉄の蓄えは、通常の血液検査に変化が出るより前に減り、疲れ、階段での息切れ、抜け毛、爪が割れやすい、寒がりといったことがその時点で出てきます。特徴的なヒントは、氷をかじりたくなることと、夜に脚がむずむずすることです。

**やること:**

- **フェリチンの検査を頼む** — 蓄えを示す最も大切な指標です。鉄は検査に基づいて。やみくもに飲まないでください。鉄のとりすぎも害になります。
- **鉄を含む食事。** 最も吸収されやすいのは、肉、鶏肉、魚、魚介類の鉄です。植物性の鉄 — レンズ豆、いんげん豆、豆腐、かぼちゃの種、濃い緑の野菜 — は、同じ食事でビタミンCと組み合わせましょう。パプリカ、柑橘類、キウイ。
- **お茶、コーヒー、乳製品は、鉄を含む食事とは時間をずらして**、1時間ほどあけて。吸収を妨げるからです。

そしていちばん大切なこと:多い月経は解決できます。婦人科には、出血量を何分の一にも減らす方法があります。原因に向き合わない鉄の補給は、根本的な解決ではなく応急処置です。

## 記録することが、半分の仕事

VIA-Lで月経の初日を記録しましょう。数周期たつと周期の長さがどう変わっているかが見え、医師にも相談しやすくなります。日記は、周期が睡眠、気分、ホットフラッシュとどう関係しているかを知る助けにもなります。

## 必要ないもの

- **「周期のフェーズ別」サプリメントのセット** — マーケティングです。フェーズ別に飲んでも、毎日飲むのと変わりません。
- **「フェーズ別のシード」** — 臨床データはありません。種子類は食べ物としては体によいのですが、日ごとに替えても何も変わりません。

## すぐに医師に相談すべきとき

- ナプキンやタンポンを、数時間続けて1時間ごとに替えなければならない。
- 月経が8日より長く続く。
- 月経と月経の間、または性交後の出血。
- 強い疲れ、息切れ、めまい、失神を伴う出血。
- **月経がない状態が12か月続いたあとの出血は、どんなものでも** — すぐに婦人科を受診する理由になります。

## 今週試してみること

- VIA-Lで月経の初日を記録する。
- 月経が多いなら、鉄を含む食事をビタミンCと一緒に。お茶とコーヒーは1時間あとに。
- 「多い」に自分が当てはまったら、婦人科を予約してフェリチンの検査を頼む。
