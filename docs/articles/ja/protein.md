# 朝食から、毎食タンパク質を:40歳を過ぎるとなぜ多く必要なのか

*3分で読めます*

朝はコーヒーとクッキー、昼は急いで何か、夜にきちんとした夕食。とても多くの人がこんなふうに食べています。そしてこの食べ方では、夜までタンパク質がほとんどありません。40歳を過ぎると、これが力にも、筋肉にも、甘いものへの欲求にもはっきり表れます。

## なぜ効くのか

**筋肉が「要求の多い」ものになった。** 40歳を過ぎると、筋肉はタンパク質への反応が鈍くなります。だから筋肉を守るには、以前より多くのタンパク質が必要です。それも夕食でまとめてではなく、1日を通して均等に。

**タンパク質は満腹感と安定した血糖をもたらす。** タンパク質の多い食事は長く満腹感が続き、血糖の急上昇をやわらげます。落ち込みも、甘いものへの欲求も減ります。

**タンパク質の多い朝食は1日をならす。** 朝食を抜いたり「空っぽの」朝食にしたりすると、ストレスホルモンが高いままになり、日中にがくっと落ち込みます。起きてから1〜2時間以内に朝食をとるのがよいでしょう。

## やり方

- **毎食にタンパク質源を。** 目安は1回の食事で30〜40 gのタンパク質。
- **朝食から始める:**たいてい朝食がいちばんタンパク質が少ないからです。
- **1日で**は、体重1キロあたり少なくとも1〜1.2 gのタンパク質。筋トレをしているならそれ以上に。

30〜40 gのタンパク質が実際にどのくらいかというと、おおよそ:

- 朝食:卵2〜3個のオムレツにカッテージチーズ、またはナッツをのせたギリシャヨーグルト。
- 昼食:手のひら大の魚、鶏肉、または肉。
- 夕食:レンズ豆やいんげん豆と豆腐、チーズ、魚介類。

プロテインパウダーは、食事でとりきれないときの便利な補助になります。

## 注意が必要な人

- **腎臓の病気がある場合**は、タンパク質の量を必ず医師と相談してください。
- **食事に関する困難がある場合** — いま、または過去の摂食障害 — 食事のルールは自分で取り入れるより、専門家と話し合うほうがよいでしょう。

## 妨げになりそうなこと

- 「朝は食べられない」。少しから始めましょう。ヨーグルト、卵、ケフィア1杯。
- 「料理する時間がない」。ゆで卵、カッテージチーズ、魚の缶詰、調理済みのレンズ豆なら、料理はいりません。

## 期待できること

食事と食事の間の満腹感と、甘いものへの欲求がどう変わるかを見てください。VIA-Lで力と体調を記録しましょう。

## このステップが役立つ人

疲れ、太くなるウエスト、筋力の低下、関節のうずきがある人。筋トレと組み合わせるとよく効きます。
