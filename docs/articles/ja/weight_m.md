# おなかが出てくる:40歳を過ぎた男性に起きる理由と、本当に効くこと

*5分で読めます*

食べる量は前と変わらないはずなのに、ベルトの穴をひとつずらさなければならない。おなかは目立ってきたのに、体重計の数字はそれほどでもない。これは単なる「年のせい」ではありません。おなかの脂肪には独自の理屈があり、独自の手段があります。

## ひとつの根っこ、たくさんの結果

おなかまわりの脂肪は、皮膚の下の脂肪とは違います。体の内側、内臓のまわりにあり、活発な組織として働きます。そこから、別々に見えるいくつものことが生まれます:

- 体が糖にうまく反応しなくなる;
- テストステロンが下がる;
- 勃起の問題が出てくる;
- 肝臓に脂肪がたまる;
- 心臓と血管のリスクが高まる。

大切なこと:脂肪がテストステロンを下げる力は、低いテストステロンが脂肪を増やす力より強いのです。だから「ホルモンを上げておなかの脂肪を燃やす」はうまくいきません。逆向きにうまくいきます。ウエストが細くなれば、テストステロンが上がります。

## 体重ではなくウエストを測る

体重計は筋肉と脂肪を区別できず、脂肪がどこにあるかも見えません。外から見るとやせていても、内側に脂肪がある人もいます。家でできる最も確かな目安は**ウエストが身長の半分未満**であることです。たとえば身長180 cmなら90 cm未満。ウエストが102 cm前後なら注意して見ていくサインです(アジア人の体格なら90 cm前後)。これは目安であって、判定ではありません。

## 効くこと:強い順に

**体重を5〜10%減らす。** いちばんの手段です。血糖、血圧、肝臓、テストステロンを一度に好転させます。体重計の数字より、ウエストがどれだけ細くなったかが大切です。

**超加工食品をやめる。** スナック、ファストフード、甘い飲み物は、それだけで食べすぎを招きます。地中海式の普通の食事に切り替えることが、カロリー面で最大の手段です。

**筋トレと有酸素運動を一緒に。** 糖の大部分を取りこむのは筋肉です。目安は、週に150分のウォーキングなどの有酸素運動と、2〜3回の筋トレ。

**タンパク質と食物繊維。** タンパク質は体重1キロあたり1.2〜1.6 g。やせるときに筋肉ではなく脂肪が落ちるようにするためです。野菜、豆類、全粒穀物の食物繊維は1日25〜35 g。

**食べる順番と食後のウォーキング。** 野菜とタンパク質を炭水化物より先に、そして食後に10〜15分歩く。血糖の急上昇がなだらかになります。

**7時間以上の睡眠。** 睡眠不足は、まさにおなかの脂肪と食欲を増やします。睡眠を1時間延ばすと、食べすぎたい気持ちがはっきり弱まります。

**お酒と甘い飲み物を減らす。** 「ビール腹」はビールだけでなく、お酒全般の影響です。

## 肝臓について

肝臓の脂肪は、出てきたおなかによく静かについてくる存在です。症状はなく、3人に2人では通常の肝臓の検査も正常です。ALTが正常でも否定できません。リスクを評価するのは医師です。

## 避けたほうがいいもの

- **ベルベリン**は、本物ですが控えめな効果があり、多くの薬と相互作用します。治療の代わりにはなりません。医師に相談してください。
- **「テストステロンブースター」**でおなかはへこみません。やせるほうが、どれよりも確実にテストステロンを上げます。
- **血糖が正常なのに使う「最適化のための」血糖センサー。** 不安が増えるだけです。
- **医師を通さないやせるための注射。** これは処方薬です。本当に効きますが、医師の管理のもとで、タンパク質と筋トレと一緒に使うものです。

## 医師に相談したほうがいいとき

- 強いのどの渇き、頻尿、原因のわからない体重減少:すぐに血糖を調べてもらう。
- ウエストが102 cm以上で、家族に糖尿病の人がいる、疲れがある、首やわきの下に黒っぽいビロードのようなしみがある。
- 急に腫れて赤く熱をもち、ひどく痛む関節。足の親指に多く、夜に起きることが多い。

## 今週試してみること

- ウエストを測って記録する。
- メインの食事のあとに10〜15分歩く。
- 甘い飲み物をやめる1週間。
