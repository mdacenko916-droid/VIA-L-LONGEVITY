# 40歳を過ぎた男性の検査:テストステロンと、もっと大切なこと

*4分で読めます*

多くの男性は「ホルモン」から始めたがります。テストステロンを測って、答えを数字で見たいのです。けれども40歳を過ぎて本当に役立つ検査は、別のことに関わっています。心臓、血管、そして代謝です。何年も痛まないまま進み、あとで大きく効いてくるものを見つけるのは、これらの検査です。

## テストステロン:だまされないための測り方

- **朝に。** 値は1日のうちで変わるので、朝の検査が基準になります。
- **2回。** 1回の検査ではほとんどわかりません。テストステロンが低いかどうかは、朝の結果2回分をもとに、医師と一緒に判断します。
- **体調が悪いときは避ける。** かぜ、インフルエンザ、急な病気のときは、テストステロンが一時的に下がるので、結果があてになりません。

そして覚えておいてください。40歳を過ぎてテストステロンが低いのは、それが原因というより、体の調子が悪いことを示している場合のほうが多いのです。詳しくは「男性更年期(アンドロポーズ):40歳を過ぎた男性に本当に起きていること」の記事で。

## 自分の数値を知る:心臓と代謝にとっての要点

- **血圧**:定期的に、検証済みの上腕式の血圧計で。
- **血糖**:空腹時血糖またはHbA1c。
- **脂質**、できれば**ApoB**も:ふつうの「悪玉コレステロール」より正確に、血管に危険な粒子を示します。
- **Lp(a)**:一生に一度測れば十分です。遺伝によるもので、およそ5人に1人で高くなっています。
- **hs-CRP**:医師が指示した場合の、慢性的な炎症の指標です。目安は1未満、1〜3、3 mg/Lより上。10を超える場合は急な感染症のことが多く、2〜3週間後に測り直します。1回だけの値はあてになりません。

心臓のリスクが中くらいなら、医師が**冠動脈カルシウム**(CAC)の検査をすすめることがあります。スタチンが必要かどうかを決める助けになる、短い検査です。

## 年齢やサインに応じて、ほかに

- **大腸がん検診:45歳から。** 大腸内視鏡か便の検査です。どんな食事法やサプリメントも代わりにはなりません。
- **PSA**は、医師と相談して決める個人的な判断です。メリットはありますが、不要な心配や処置も少なくありません。家族に前立腺がんの人がいれば、早めに相談しましょう。
- **甲状腺**:男性では病気はまれなので、TSHはサインがあるときに、医師の指示で測ります。「髪と爪のための」サプリメントに入っているビオチンは結果を狂わせるので、数日前にやめます。

## 測らなくていいもの

- **「ストレスを確かめるための」コルチゾール。** 特定の病気のための検査で、体調の確認用ではありません。疲れた男性では、誤った警報が出ます。
- **有料の腸内細菌の検査。** 同じ検体でも、検査機関によって違う答えが出ます。
- **血糖が正常なのに使う「最適化のための」血糖センサー。** 食後の上昇は健康な人でも普通のことで、センサーは不安を増やすだけです。

## 腕時計や指輪型デバイスは?

傾向やサインは示してくれますが、動脈のプラークもコレステロールも見えず、血圧も確実には測れません。不規則なリズムの通知は医師に見せる価値があります。けれども通知が**ない**ことは何も除外しません。リズムの乱れも、無呼吸もです。「完璧な」画面は検査の代わりになりません。

## 今週試してみること

- 家で朝と夜に血圧を測る。2〜3日続けて。
- 最近の検査結果を探す:リストのうち、すでにあるもの、足りないもの。
- 医師に相談したいことのリストを作る。
