# 閉経移行期(ペリメノポーズ)とは? その見分け方

*4分で読めます*

眠りが浅くなった、月経が予測しにくくなった、気分が揺れる。それなのに検査は「異常なし」。心当たりはありませんか? その背景には、閉経移行期(ペリメノポーズ)があることがとても多いのです。最後の月経の前の数年間のことです。これは病気ではなく、すべての女性が通る段階です。けれどもほとんど語られないため、何が起きているのか何年もわからないままの人が少なくありません。

## 体の中で起きていること

移行期のホルモンは、なめらかに、同時に変わるわけではありません。

**プロゲステロンは最初に、一定のペースで下がります。** 40歳を過ぎると、排卵のない周期が少しずつ増えます。これは移行期のごく普通の一部です。プロゲステロンは脳の自然な「鎮静役」を支えているため、その低下はまず寝つきの悪さとして感じられることが多いのです。

**エストロゲンはこの時期、下がるのではなく揺れます。** 下がったかと思えば普段より高く跳ね上がり、その後でようやく最終的に下がっていきます。この時期の体調を揺さぶる主な原因は、レベルそのものではなく、この揺れの大きさです。「何が何だかわからない」と感じるのはそのためです。いい週があったと思えば、次の週はつらい、というように。

## 見分け方

閉経移行期は、1回の検査ではなく、時間をかけて見えてくる全体像でわかります。よくあるサインは次のとおりです。

- **周期が変わる。** 35〜50歳で、月経が多くなる、長くなる、不規則になることがよくあります。
- **睡眠。** 寝つきにくい、夜中に目が覚めることが増える、頭が「オフにならない」。
- **気分。** 気分の波やイライラ。月経前の時期が以前より強く感じられる。
- **胸とむくみ。** 胸の張りや痛み、おなかの張り。
- **頭。** 片頭痛、頭の「もや」、集中しにくさ。
- **ホットフラッシュと寝汗。** この時期から始まることもあります。

すべてが一度にそろう必要はありません。大事なのはパターンです。何がくり返し起きていて、それが周期とどう関係しているか。

## まずやること

**記録を始める。** 月経の初日、睡眠、ホットフラッシュ、気分を、毎日短く。数週間たつと、記憶ではとらえきれないつながりが見えてきます。これこそが移行期のいちばんの「検査」です。

**睡眠のいかりを置く。** 週末も含め、7日間とも同じ時刻に起きること。そして起きてから1時間以内に10〜15分、日の光を浴びること。これは睡眠にとって最も強い生活習慣の手段で、どんなサプリメントよりも効果があります。

**夜を揺さぶるものを減らす。** コーヒーや濃いお茶は14時まで。夜はお酒なしで。お酒は眠りに誘いますが、夜の後半の眠りを削ります。

**月経が多いなら鉄をチェック。** 多い月経は、女性の鉄不足の最もよくある原因です。鉄の蓄えは、通常の血液検査に変化が出るより前に減っていきます。疲れ、階段での息切れ、抜け毛があれば、医師にフェリチンの検査を頼むきっかけになります。鉄は検査に基づいて。やみくもに飲まないでください。

## すぐに医師に相談すべきとき

- ナプキンやタンポンを、数時間続けて1時間ごとに替えなければならない。
- 月経が8日より長く続く。
- 月経と月経の間の出血。
- 強い疲れやめまいを伴う出血。

これは「ただの移行期」ではありません。こうしたサインは婦人科で診てもらう必要があります。

- コーヒーは14時まで、夜はお酒なし。
