# 野菜とタンパク質を炭水化物より先に:同じ食事でも、血糖にやさしく

*3分で読めます*

このステップは、食べる量を減らすことでも、好きなものをがまんすることでもありません。順番の話です。何を最初に食べるか。お皿の上で順番を入れ替えるだけで、体が食事を処理するやり方がはっきり変わります。

## なぜ効くのか

食事を野菜とタンパク質から始め、パン、穀物、じゃがいも、パスタをそのあとに食べると、食後の血糖の上昇がおだやかになります。およそ3分の1です。上昇が小さければ、そのあとの落ち込みも小さくなります。昼食後の眠気も、甘いものへの欲求も減ります。

移行期には体の糖への反応が鈍くなるので、こうしたシンプルな工夫が特に役立ちます。そして食後に歩くことと組み合わせると、効果が足し算になります。

## やり方

- **まず野菜** — サラダ、煮た野菜や生野菜。
- **次にタンパク質** — 肉、魚、卵、豆腐、豆類。
- **炭水化物は最後に:**付け合わせ、パン。

全部同じお皿で、ただこの順番に。食べる量を減らす必要はありません。

## 注意が必要な人

- **食事に関する困難がある場合** — いま、または過去の摂食障害 — 食事のルールは自分で取り入れるより、専門家と話し合うほうがよいでしょう。
- **ワルファリンを飲んでいる場合:**緑の野菜の量を急に変えないでください。薬の効き方がそれに左右されます。食事の変更は医師と相談しましょう。

## 妨げになりそうなこと

- 「野菜がない」。冷凍野菜や、きゅうり、トマト、パプリカを切っただけのものでかまいません。
- 「よそのお宅やカフェでは」。サラダか野菜の前菜から始め、パンはそのあとに。
- 「朝食はおかゆかサンドイッチ」。まず卵、カッテージチーズ、または野菜を足しましょう。

## 期待できること

食後の満腹感、昼食後の眠気、甘いものへの欲求を見てください。体重の変化はもっとゆっくりなので、体調を目安にしましょう。VIA-Lで記録してください。
