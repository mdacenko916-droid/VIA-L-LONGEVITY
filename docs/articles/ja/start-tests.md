# 40代以降のホルモン検査では、なぜあまりわからないのか

*4分で読めます*

体調が変わってきたとき、まず思うのは「ホルモンを測って」答えを数字で見たい、ということです。けれども移行期には、まさにこの検査がいちばん当てにならないのです。その理由と、本当に受ける価値のある検査を見ていきましょう。

## ホルモンが検査でとらえられない理由

**揺れているから。** 閉経移行期のエストロゲンは上がったり下がったりします。40代以降のFSH、エストラジオール、プロゲステロンは大きく変動するため、1回の検査はたまたまの1日のスナップ写真にすぎません。明日になれば数値は違います。

**プロゲステロンは脈打つように変わるから。** 血中の濃度は、わずか数分で何倍も変わります。血液検査でさえ一瞬しか示しませんし、家庭用の検査ではまったく測れません。

**ガジェットはホルモンを測らないから。** 指輪型や腕時計型のデバイスは、排卵後の体温の上昇をとらえます。ただし後になってから、目印としてだけです。上昇がなかったからといって「プロゲステロンが少ない」わけではありません。40歳を過ぎると排卵のない周期もありますし、センサーのノイズ、ホットフラッシュ、かぜのこともあります。

だから閉経移行期は、検査ではなく、時間の中での全体像でわかります。周期、睡眠、気分、ホットフラッシュがどう変わっていくか。数週間の日記は、1枚の検査結果よりも多くを語ります。

## 除外しておきたいこと

移行期の症状の一部は、別の状態とよく似ています。それらは簡単に調べられ、対処もできます。まずこれらを除外しておきましょう。

- **甲状腺** — 寒がり、便秘、脈が遅いといったことが出てきたら、TSHの検査。
- **鉄の蓄え** — 月経が多い、疲れ、階段での息切れ、氷をかじりたくなる、夜に脚がむずむずする、といったことがあれば、フェリチンの検査。鉄は、通常の血液検査に変化が出るより前に減っていきます。
- **気分** — 落ち込みや不安が月経前だけでなく1か月じゅう続くなら、それだけで医師に相談する理由になります。
- **睡眠中の呼吸** — 途切れるいびき、すっきりしない眠り、日中の眠気。閉経後には、これは疲れのよくある原因で、見落とされがちです。

## 40代以降に本当に役立つ検査

- **血圧と血糖** — 定期的に。
- **ApoB** — 通常の「悪玉コレステロール」よりも正確に、血管にとって危険な粒子を示します。
- **Lp(a)** — 一生に一度測れば十分です。遺伝的なもので、閉経後に上がります。
- **hs-CRP** — 慢性的な炎症の指標。女性では心臓のリスクをよく予測します。
- **フェリチンとTSH** — 上のサインに応じて。
- **骨密度検査** — リスク要因があれば閉経の時点で。45歳より前の閉経、軽いけがでの骨折、ステロイドの長期使用、親の大腿骨骨折。

医師には「コレステロール」だけでなく、できればApoBとLp(a)も頼みましょう。

## 今週試してみること

- VIA-Lで日記を始める:月経の初日、睡眠、ホットフラッシュ、気分。
- 「除外しておきたいこと」のリストから、自分に当てはまるものを書き出す。
- 医師と相談したい検査のリストを作る。
