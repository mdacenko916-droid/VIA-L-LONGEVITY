# 食後に歩く:1日を変える10分

*3分で読めます*

昼食のあとに眠くなり、2〜3時間すると甘いものが欲しくなり、夕方には力が残っていない。これは「性格」ではなく、食後の血糖のジェットコースターであることが多いのです。そしてそれに対する最もシンプルな方法のひとつが、食べてすぐの短い散歩です。

## なぜ効くのか

食後には血液中の糖が上がります。筋肉が動くと、筋肉は糖を取りこみます。これはふだんのルートに加わる、糖を処理する別のルートです。ピークが低くなり、そのぶん後の落ち込みも小さくなります。眠気も、甘いものへの欲求も減ります。

歩くことは、別のステップ「野菜とタンパク質を炭水化物より先に」と組み合わせると特によく効きます。効果が足し算になるのです。

## やり方

- **メインの食事のあとに10〜15分歩く。** 1時間後ではなく、食べてすぐがベストです。
- **ペースはふつうに、** 話ができるくらいで。これはトレーニングではなく、体を動かすことです。
- **外に出られなければ** — 家の中を歩く、階段を使う、片づけをする、立って食器を洗う。

## 注意が必要な人

- **糖尿病の薬:**新しい運動では、血糖がいつもより下がることがあります。すぐ食べられる軽食を手元に置き、力が抜ける、ふるえるといったときはやめましょう。
- **けが、病気、発熱** — まず治すことが先です。このステップは待ってくれます。

## 妨げになりそうなこと

- デスクワーク。昼食後の短い散歩、歩きながらの電話、エレベーターの代わりに階段。
- 天気。家の中やショッピングモールで歩くのも数に入ります。
- 夜。夕食後の10分でも、すぐにソファに座るよりずっとよいのです。

昼食後の眠気と、甘いものへの欲求を見てください。VIA-Lで力と体調を記録しましょう。
