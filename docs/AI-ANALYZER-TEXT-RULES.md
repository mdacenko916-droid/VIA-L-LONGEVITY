## Главный принцип: ТЕРМИН ≠ CLAIM

Регуляторный риск (App Store 1.4.1 / EU MDR / FTC) — в **характере утверждения**, НЕ в словах.
Физиологический термин безопасен; опасно — заявить об **измерении**, **диагнозе** или **причине болезни**.

**Почему так (контекст решения):**
- VIO **никогда не подавался** в App Store → прежний «гарантированный реджект за слова» был гипотезой, не фактом.
- **Apple Health (iOS 27, июнь 2026)** сама использует «menopause / perimenopause» напрямую, с рамкой «suggestive of» + дисклеймер. Гейткипер легитимизировал терминологию.

## ❌ ЗАПРЕЩЕНО (это claims — держим гардами)

| Класс | ❌ Нельзя | ✅ Надо |
|---|---|---|
| **Замер** (прибор не мерил гормоны/лаб) | «ваш кортизол повышен», «эстроген низкий», «ваш HRV показывает» | «ритмы стресса», «как тело отвечает на нагрузку» |
| **Диагноз / болезнь как факт** | «у вас гипотиреоз / остеопороз / диабет / апноэ» | «паттерн, иногда встречающийся при… — стоит обсудить со специалистом» |
| **Каузальность** | «X — прямое следствие Y», «вызвал / приводит к / напрямую влияет» | «может быть одним из факторов», «иногда сопровождается» |
| **Exclusion-claim** (симметрично диагнозу) | «это не возрастное, а усталость», «приборы показывают, что не гормональное» | «естественны некоторые сдвиги, но паттерн часто связан с [Y] — если сохранится, стоит обсудить со специалистом» |
| **«=»-формулы** (каузальная математика) | «стресс + поздние ночи = повышенный пульс» | «стресс и поздние ночи часто идут рука об руку с повышенным пульсом» |
| **Вердикт нормы** | «это норма / не норма», «в норме» | «частое явление», «в обычном диапазоне» |
| **Обещание результата** | «сон восстановится», «энергия вернётся», «через 2 недели пройдёт» | «регулярный ритм помогает телу легче находить спокойный сон» |
| **Приказной/лечебный тон** | «терапия / протокол / назначаю / пациент / обязательно / лечит / предотвращает» | «можно попробовать», «многим помогает», «ориентир» |
| **Гормональные травы с дозой/режимом** | «витекс 200 мг утром», «ашваганда 600 мг» | не рекомендовать (safety: взаимодействия) |

## Калибровка уверенности (3 уровня — тон, закреплён в промпте И в regen)

Эксперт уверен в общеизвестном, сдержан ТОЛЬКО о данных клиента. Не мямлить одинаково про всё:
1. **Общее знание / советы-действия** → УВЕРЕННО, без «может»: «Клетчатка держит сахар ровнее», «Ложитесь раньше».
2. **Интерпретация данных клиента** (его метрики → его состояние) → ОДИН смягчитель на мысль, разными словами (часто/похоже/обычно/нередко), не монотонное «может» подряд.
3. **Результат для клиента** → не обещать как факт будущего.

⚠️ **Эвфемизм/тон-правила живут в ПЯТИ+ местах промпт-сборки — правь ВСЕ (иначе модель парротит эвфемизм из непочищенного блока):**
`AI_SAFETY_RULES` · `WELLNESS_STYLE_OURA` · `WELLNESS_SYSTEM_PROMPT` (словарь + KB-контент) · regen-промпт `wellnessGuardrail` (~489) · **per-endpoint [WELLNESS]-гарды**: `/analyze` (~1452), `/day-plan` (~1822), `/advisor-chat` (~4320). Урок 2026-07-12: де-эвфемизировал словарь, но [WELLNESS]-гарды всё ещё МАНДАТИЛИ «менопауза→переходный этап», «приливы→тепловые волны», «гормональный→внутренний баланс» → вывод парротил. Разрешить прямой термин ≠ запретить эвфемизм: нужна и негативная инструкция «НЕ используй расплывчатые внутренний баланс/переходный этап».

⚠️ **Правило (старое) про ТРИ места калибровки уверенности** — `AI_SAFETY_RULES`, `WELLNESS_STYLE_OURA` И **regen-промпте `wellnessGuardrail`** (стр. ~489). Урок 2026-07-11: regen-промпт имел свою инструкцию «no certainty words» и механически хеджил каждую фразу при перегенерации, перекрывая калибровку основного промпта (44 хеджа/текст). При правке тон-правил — правь ВСЕ ТРИ места, иначе regen-путь перепишет по-своему. Вторая ловушка: при переписывании regen-промпта легко потерять его claim-правила (no causation / no equations) — они там ОБЯЗАНЫ остаться.

## Механизм (что где живёт в `cloudflare-worker.js`)

**Тарифная развилка:** `isWellness = ['vio','pro']` (стр.~1461). Гарды применяются ТОЛЬКО к VIO/PRO (стр.~1544). EXPERT/ELITE — клинический `SYSTEM_PROMPT`, прямые термины, БЕЗ скраба.

**Три слоя (для VIO/PRO):**
1. **Промпт** (вероятностный): `WELLNESS_STYLE_OURA` (593/596), `WELLNESS_SYSTEM_PROMPT` (622-627 «термин≠утверждение»), `AI_SAFETY_RULES`, `FEW_SHOT_SAFE`.
2. **Guardrail** `regex → self-check → regen` (`AI_RISK_RE` ловит только CLAIM-маркеры: диагноз/болезнь/каузальность/абсолюты/лечение/**exclusion-claim** «это не возрастн-/гормональн-», «приборы показыва-» — НЕ термины).
3. **Детерминированный скраб** `wellnessHardScrub` — только CLAIM-гаранты (см. ниже).

**ЖИВЫЕ claim-гаранты (НЕ трогать):**
- `_stripHerbLines` — вырезает строку с гормональной травой (не переодевает).
- `_stripCodeTokens` — вырезает утёкшие snake_case-коды полей.
- `_RU_HORMONE_CONTEXT` — теперь ТОЛЬКО вердикт-нормы («это норма/нормально/нормальные/в норме»).
- `_FEED_DEMED` — теперь ТОЛЬКО болезни/органы/лекарства/протоколы + лаб-маркеры (ТТГ/АТ-ТПО/св.Т3-4 — measurement-guard) + «диагноз/патология».
