# Фото-каталог блюд: чего не хватает и как доснять

**Дата:** 2026-08-26. Каталог живёт в `interpreter/food/*.webp`, ключи — в промпте «Памятки дня»
(`cloudflare-worker.js`, строки «Завтраки/Обеды/Ужины/Перекусы»). Сейчас 22 блюда + тарелка.
Задача — закрыть дыры, которые открылись вместе с временными слоями из
[`NUTRITION-MAPPING-SPEC.md`](NUTRITION-MAPPING-SPEC.md) §3.3.

---

## 1. Почему нужны новые блюда

Слой ограничивает продукты, а каталог должен оставить человеку выбор. Посчитал по текущим 22:

| Слой / акцент | Сколько блюд подходит сейчас | Достаточно? |
|---|---|---|
| **Без глютена** (целиакия) | завтраки 3 из 6, обеды 4 из 6, ужины 5 из 6 | завтраков мало |
| **Low-FODMAP** (СРК) | по 1–2 на приём | **нет, главная дыра** |
| **Щадящий вечер** (рефлюкс) | 1 ужин (суп) | мало |
| **Вегетарианские** | обеды 2, ужины 0, завтраки 2 | ужина нет вовсе |
| **Кальций из еды** (сардины с костями) | 0 | нет |
| **Железо + витамин C в одном приёме** | 0 (говядина есть, витамина C рядом нет) | нет |

Пока блюда не размечены, слой работает только как текст модели: она может сказать «без глютена»
и всё равно предложить вариант с хлебом. После разметки код будет отдавать модели только
разрешённые ключи.

## 2. Требования к фото (обязательно соблюсти — иначе каталог развалится по стилю)

- **512 × 512, WebP**, вес ~20–30 КБ.
- Одна **круглая чёрная матовая тарелка**, вид сверху под углом примерно 30–40°.
- **Фон чисто белый**, мягкая тень под тарелкой, никаких столов, скатертей, приборов, рук, зелени
  по краям, надписей и логотипов.
- Порция на одного, еда занимает большую часть тарелки, компоненты видны раздельно
  (белок · гарнир · овощи), без соусов-луж.
- Свет мягкий рассеянный, тёплый, без резких бликов и без «глянцевого фуд-порно».
- Именование файла = ключ из таблицы ниже, строчными: `bf_*` завтрак, `ln_*` обед, `dn_*` ужин,
  `sn_*` перекус.

Готовый промпт-шаблон для генерации (подставить состав):

> Photorealistic food photography, single serving on one round matte black plate, three-quarter
> top-down view, pure white seamless background, soft diffused warm light, gentle shadow under the
> plate, no cutlery, no props, no text. The plate contains: **[состав]**. Components clearly
> separated, appetising but natural home cooking, not glossy advertising style. Square 1:1.

## 4. Что делаю я после того, как фото появятся

1. Кладу файлы в `interpreter/food/` (и они автоматически попадают в бандл приложения через
   `app/sync-web.sh`).
2. Завожу `DISH_TAGS` в воркере: у каждого ключа метки `gf` · `lowfod` · `soft` (щадящий) · `veg`.
3. `buildDietBlock` начинает отдавать модели **только разрешённые ключи**: при целиакии — ни одного
   варианта с глютеном, при low-FODMAP-курсе — только помеченные, и так далее.
4. Размечаю и старые 22 блюда — часть из них уже подходит, просто про это никто не знает.
