## ⚖️ Принципы (не забыть — это уроки треда)
1. **Safety > косметика.** Клинический красный флаг НЕЛЬЗЯ чинить эвфемизмом — это релексикализация-маскирует-симптом, даёт зелёный мех-скану. См. §1.
2. **Чинить в ИСТОЧНИКЕ, не латать вывод.** Часть флагов — прямо в промпте (стр. указаны) → правится один раз, а не whack-a-mole по генерации.
3. **Детерминированный гарант — для хард-классов** (утёкшие коды, гормональные травы). **Промпт/few-shot — для тона/семантики.**
4. **Зелёный мех-скан ≠ compliance** — после RC2 обязателен человеческий глаз по полному тексту.

**Триаж красного флага менструации.** Кейс: ИИ объяснил «обильные менструации + короткий цикл (24 дня)» образом жизни (стресс/белок/сон).

## 📐 §2. Структурный редизайн (дизайн + рендер)
Разбор/Памятка сейчас = статья/консультант. Нужен **персональный наставник-помогает-действовать**.

**Единый шаблон КАЖДОГО блока (утро/вода/питание/движение/вечер/сон):**
1. **Что сделать сегодня** — 3–5 коротких **☐-чек-пунктов** (действия, императив).
2. **Что выбрать** — если есть варианты (☐ список: завтрак/обед/ужин).
3. **Если уже используете…** — добавки/практики/аксессуары (☐, рамка «если», не назначение).

**Заголовки — глагольные (императив), не существительные:**
| Было | Стало |
|--|--|
| Утренний старт | Начните утро спокойно / Что сделать утром |
| Водный баланс | Поддерживайте водный баланс |
| Питание и энергия | Что сделать для энергии |
| Движение / Силовые и опорные нагрузки | Добавьте движение / Укрепляйте тело |
| Сон / Поведенческие ориентиры для глубокого сна | Подготовьтесь ко сну |
| Нутрицевтики утра/вечера | Если уже используете добавки |

**Правило длины:** видимая часть короткая; объяснения «почему полезно» → в **раскрывашку «Почему это может помочь» / «Подробнее»**. Сейчас вода ~8 строк, сон ~14, движение ~9, ужин ~12 — несколько экранов, не читается целиком.

**Реализация:** промпт воркера (генерит заголовки+структуру; сейчас стр.593 велит «БЕЗ ярлыков-заголовков, живым текстом» — **пересмотреть**) + клиентский **☐-рендер** (`_dpInner`) + синхронный фолбэк `_bpChapterData`.
