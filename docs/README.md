# Проект «Кабинет / Платформа» — точка входа

Эта папка `docs/` = весь замысел кабинета и платформы в одном месте. Новый чат начинает
**отсюда**: прочитать этот файл → открыть нужную спеку.

## Источник правды

**[`PLATFORM-MODEL.md`](PLATFORM-MODEL.md)** — главная спека платформы и единственный источник
правды. Все новые мысли по платформе/онлайну пишем **только сюда**, не в журнал.

- §1–9 — офлайн-модель (специалист приводит своих пациентов, мы — инструмент за аренду).
- §10 — онлайн-модель (специалист ведёт удалённо, пациент на PRO; оба платят нам).
