# Матрица «сигнал → пищевой паттерн» для VIA-L и VIA-L EXPERT

**Дата:** 2026-08-26. Основа — ТЗ специалиста «Жалоба/диагноз → диетический паттерн»
(`скрин/1/via-l nutrition-mapping TZ.pdf`). Здесь — та же идея, переложенная на нашу
архитектуру и на ограничения App Store. Смежное: `interpreter/ARCHITECTURE.md` §4 (промпт и KB),
`docs/KB-PATTERN-AUDIT.md`, `docs/BLOOD-PRESSURE-EVIDENCE.md`, `docs/INDEX-SCORING-SOURCES.md`.

## 0. Что берём из исходного ТЗ и что меняем

**Берём целиком:** главную мысль — универсальная «гарвардская тарелка» одинакова для всех и
поэтому ничего не стоит; рекомендация должна выбираться под конкретный сигнал клиента, а не
пересказывать общие принципы. Берём и форму ответа: паттерн → 3–5 продуктов → 2–3 ограничения →
«почему именно это» с привязкой к жалобе, плюс пометка силы доказательств.

**Меняем пять вещей, иначе не заработает:**

1. **Вход — не диагноз, а наш сигнал.** VIA-L идёт в App Store как велнес: диагноза («СРК»,
   «преддиабет», «гипертония», «остеопороз») там нет ни на входе, ни на выходе — Guideline 1.4.1,
   и в коде стоят фильтры, которые вырезают диагноз из текста. Мы не спрашиваем диагнозы и не
   имеем анамнеза в свободной форме, зато у нас уже есть структурированные сигналы: жалоба из
   `CMP_ITEMS`, чекбоксы ЖКТ, домашнее давление, талия/рост, введённые анализы, лекарства,
   фаза, приливы, сон, стресс. Матрица должна ключеваться на них. В **VIA-L EXPERT** диагноз
   допустим (продукт вне стора, ведёт специалист) — там тот же каталог паттернов принимает
   диагноз из карточки как дополнительный вход.
2. **Арбитраж конфликтов — код, а не инструкция модели.** В ТЗ пункт «искать пересечение, при
   конфликте называть иерархию» адресован интерпретатору. У нас уже есть измеренный факт: чек-лист
   в промпте модель исполняет через раз, а приписка в хвост длинного промпта не исполняется
   вовсе. Значит: паттерны выбирает и мирит между собой **детерминированная функция**, а модель
   получает уже слитый непротиворечивый список и только формулирует текст.
3. **Появляются гейты безопасности, которых в ТЗ нет.** Половина «ключевых продуктов» в таблице
   имеет противопоказания: калиевый акцент DASH несовместим с ИАПФ/БРА, зелень и K2 — с
   антикоагулянтом, соя/фитоэстрогены — с онкологическим анамнезом груди, TRE — с сахароснижающими
   и с риском РПП, гемовое железо — только при подтверждённо низком ферритине. Без этих гейтов
   матрица опаснее универсальной тарелки, а не полезнее.
4. **У ограничительных паттернов появляется потолок длительности.** Low-FODMAP в
   потребительском приложении без срока и без реинтродукции — вред: это протокол на 4–6 недель с
   обязательным обратным вводом продуктов. Каждый ограничительный паттерн несёт поле «срок» и
   «что делать после».
5. **Паттерн управляет не только текстом разбора, но и «Памяткой дня».** Иначе выйдет так:
   в разборе написано «низко-FODMAP», а в памятке — лук, чеснок и яблоко из фото-каталога.
   Модификатор обязан фильтровать `[dish:KEY]`-каталог. Это и есть главный практический выигрыш.

## 1. Где живёт в коде

Новый детерминированный слой рядом с существующим `selectKBPatterns`:

```
selectDietPattern(data) → {
  base:      ['DP-MEDLOWGI'],           // 1–2 базовых паттерна
  modifiers: ['DM-LOWFODMAP','DM-REFLUX'],
  add:       [ {food, why, ev} … ],      // 3–5 продуктов
  limit:     [ {food, why} … ],          // 2–3 ограничения
  gates:     ['no_potassium_push'],      // что снято по безопасности
  ttl:       {'DM-LOWFODMAP': '4–6 недель, затем обратный ввод'},
  ev:        'высокая|средняя|предварительная'
}
```

Точки подключения — три, и все три обязательны:

- `/analyze` (`cloudflare-worker.js`, там же где `_kbIds = selectKBPatterns(data)`) — результат
  вживляется **внутрь блока структуры ответа**, а не в хвост промпта.
- `/dayplan` — тот же объект + фильтр фото-каталога блюд по модификаторам.
- `/weekly-report` — паттерн недели и что из него реально пробовали (петля эксперимента).

Матрица **не дублирует KB**: KB отвечает на «почему так работает» (механизм), матрица — на
«что именно есть и чего меньше». Паттерн ссылается на KB-блоки, а не переписывает их.

## 2. Вход: наши сигналы вместо диагнозов

| Сигнал у нас | Где берём | Куда ведёт |
|---|---|---|
| Жалоба (11 позиций) | `data.complaint.items` (`CMP_ITEMS`: energy, sleep, mood, fog, weight, libido, pain, hf, cycle, drive, muscle) | ось разбора; паттерн обязан отвечать именно на неё |
| Домашнее давление | `bp_sys`/`bp_dia` + тир из `_fixBpTier` | DP-DASH |

| Липиды | `labs.ldl`,`chol` | DP-MEDFIBER |
| Воспаление | `labs.crp`, боли/скованность | DP-ANTIINFL |
| ЖКТ | `gi[]` (bloating, constipation, diarrhea, reflux, heaviness) | DM-LOWFODMAP, DM-REFLUX |
| Дефициты | `labs.ferritin`,`b12`,`d`,`tsh` | DP-IRONC, DP-B12, DP-VITD |
| Приливы | `hf_count`,`hf_intensity` | DP-PHYTO (предварительная база) |
| Сон/пробуждения | `wake`,`deep`,`sleep_qual` | DP-EVENGLY (стабильный вечерний сахар + магний) |
| Стресс/тревога | `chronic_stress`,`anxiety`,`hrv` | DP-MAGN, DP-ANTIINFL |
| Кости | `bone_risk[]`, фаза post | DP-CALCK2 |
| Мышцы/саркопения | жалоба `muscle`, возраст, фаза | DP-PROTEIN |
| Мужские сигналы | `horm_male`, жалоба `drive` | DP-ZINC |
| Лекарства | `meds[]` | **гейты** (см. §5) |
| Онко-анамнез груди | `breast[]` | **гейт** на фитоэстрогены |

В EXPERT к этому добавляется диагноз из карточки специалиста — он **уточняет**, но не отменяет
сигнальный вход (диагноз может быть старым, сигнал сегодняшний).

## 3. Каталог: одна основа, акценты, временные слои

Структура переписана 2026-08-26 по выгрузке (`NUTRITION-MAPPING-EVIDENCE.md`, ответ 18): 91 %
гайдлайнов сходятся на общем ядре, и большинство «конфликтов паттернов» — это на самом деле спор
о конкретном продукте, а не о рационе. Поэтому не «выбери паттерн из таблицы», а **основа + акценты
+ временные слои**.

### 3.1 Основа (всегда, для всех)

Овощи и фрукты, цельные злаки, бобовые, орехи, рыба, минимум ультра-обработанного, умеренный
натрий. Эта основа одновременно закрывает давление, гликемию, липиды и воспаление — то есть
большую часть наших сигналов. Всё остальное — надстройка над ней, а не замена.

### 3.2 Акценты (что усилить под сигнал)

| id | Акцент | Триггер | Суть | Доказ. |
|---|---|---|---|---|
| AC-SODIUM | Натрий вниз | давление вне домашнего ориентира | главный рычаг DASH: у уже леченных натрий делает почти всю работу; эффект виден за 1–3 недели | высокая |
| AC-FIBER | Растворимая клетчатка | липиды | овёс, бобовые, орехи, оливковое масло | высокая |

| AC-B12 | B12 из еды | B12 низкий | мясо, яйца, рыба, обогащённые | высокая |

**Ретировано по выгрузке:** отдельный фитоэстрогеновый паттерн (соя и лён при приливах эффекта не
показали; лён — плацебо) и цинковый паттерн для мужчин. Соя остаётся обычной едой и источником
белка, лён — источником клетчатки; обещаний по приливам не даём. При приливах и настроении первой
строкой идёт **силовая тренировка** — там эффект сильнее (§10).

### 3.3 Временные слои (ограничительные, всегда со сроком)

| id | Слой | Триггер | Что делает | Срок |
|---|---|---|---|---|
| DM-LOWFODMAP | Ограничение ферментируемых, три фазы | вздутие + нерегулярный стул | фаза 1 — ограничение; фаза 2 — обратный ввод по одному, ~3 дня на продукт; фаза 3 — свой список | **строго 4–6 недель**; нет ответа за 2–6 недель → прекратить, это диагностический тест |
| DM-REFLUX | Режим и поза, а не запретный список | рефлюкс, изжога | интервал 2–3 ч до сна, изголовье выше, сон на левом боку, меньший объём и жирность приёма; кофе, цитрус и мяту **не запрещаем скопом** — ищем личные триггеры петлёй эксперимента | до стихания |
| DM-LATE | Не есть поздно | висцеральный жир, поздние приёмы | окно 10–12 ч; **без метаболических обещаний** — эффект в основном через меньшее количество еды, а мышцы при этом страдают первыми | 8–12 недель, потом оценка |
| DM-TEXTURE | Мягкая текстура вместо исключения | стриктуры, обострение ВЗК | готовить, измельчать — не убирать клетчатку насовсем | по состоянию |

## 4. Арбитраж конфликтов

Порядок остаётся детерминированным, но модель другая: не «два паттерна из таблицы», а **основа →
акценты → временный слой**.

1. **Основа не обсуждается** — она общая и конфликтовать не с чем.
2. **Акцентов максимум два**, приоритет по тяжести и активности сигнала: давление и гликемия →
   лабораторно подтверждённый дефицит → симптом → общее.
3. **Временный слой накладывается поверх** и в споре о конкретном продукте побеждает: бобовые
   уходят на срок протокола, но с прямой фразой «вернём через месяц, начиная с малой порции».
4. **Конфликт продукта решается выбором и таймингом, а не отменой акцента.** Так предписано
   литературой: железо и липиды — не конфликт паттернов, а вопрос источника (печень, птица, рыба)
   и тайминга (витамин C в тот же приём, чай и кофе через час).
5. **Если акцентов нет** — не выдумываем: работает основа, и мы честно говорим, что сигналов под
   отдельный акцент сегодня нет.

## 5. Гейты безопасности

Переписаны по выгрузке — половина черновых вето оказалась либо шире, либо уже нужного.

| Условие | Что делаем |
|---|---|
| ИАПФ/БРА/калийсберегающий диуретик | снимаем **солезаменители и добавки калия**; фрукты и овощи не ограничиваем (при нормальных почках пищевой калий безопасен) |
| Варфарин | **постоянство, а не избегание** зелени: не наращивать и не бросать резко; добавки K2 — нет (влияние с 10 мкг/сут) |
| DOAC (апиксабан, ривароксабан, дабигатран) | по витамину K ограничений **нет вовсе** — не пугать человека зеленью |
| Онкология груди в анамнезе | вето на **добавки изофлавонов**; цельная соевая еда безопасна (NCCN до 3 порций/сут, в т.ч. на тамоксифене) |
| Инсулин или секретагоги | вето на окно питания и на нагрузку натощак без врача |
| РПП в анамнезе или жалоба на контроль еды | вето на любые ограничительные слои, окна, счёт и граммовки — **скрининг РПП обязателен до low-FODMAP** |
| Язвенная болезнь, кровотечение ЖКТ в анамнезе, подагра | вето на окно питания |
| Хроническая болезнь почек | **не наращивать белок** (потолок 0.8 г/кг), не давать фиксированных литражей воды, не советовать солезаменители; фрукты-овощи **не ограничивать**; интерпретация анализов и любые лимиты — к врачу |
| Камни в почках | пищевой кальций **с едой поощряем** (он защищает), оксалатные продукты сочетать с кальцием, а не исключать; добавки кальция вне еды — нет; жидкость в приоритете |
| Беременность, ГВ | вето на ограничительные слои и дефицит калорий |
| Ферритин не измерен | вето на железный акцент |
| Приём добавок из профиля | сверка с `_suppCrossChecks` |

Гейт срабатывает **до** генерации текста и пишется в `gates`, чтобы недельный разбор мог объяснить,
почему совет не выдан.

## 6. Выходной контракт

Один блок в разборе, всегда в одном порядке:

1. **Что пробуем** — название паттерна человеческим языком («средиземноморский с упором на
   медленные углеводы»), без аббревиатур протоколов в VIA-L.
2. **3–5 продуктов** — конкретно, с бытовой мерой.
3. **2–3 ограничения** — с причиной, не запретом ради запрета.
4. **Почему именно это** — одна фраза, привязанная к формулировке жалобы клиента («вы пришли с
   ночными пробуждениями» → «стабильный вечерний сахар»).
5. **На чём основано** — существующая строка. Класс доказательности переводим в слова:
   высокая → «это хорошо изученный подход»; средняя → «данных меньше, но направление устойчивое»;
   предварительная → «пробуем как эксперимент, доказательства ранние».
6. **Срок** для ограничительных — обязательно.

Лексика: VIA-L может прямо писать «менопауза», «эстроген», «кортизол» — запрещены диагноз и
вердикт «у вас норма», а не слова. Формулировка всегда «обычно помогает при таком наборе
сигналов», а не «вылечит».

## 9. Блок «состояния здоровья» в опроснике (решение владельца 2026-08-26)

### 9.0 Уточнение про дозы

Порции **еды** мы уже даём и никакой модерацией они не запрещены: правило в промпте прямо
разрешает «150–200 г рыбы» и белок в г/кг. Запрещены только **дозировки добавок** (мг/мкг/МЕ,
форма вроде «глицинат») — и это наше собственное решение, а не буква правил Apple: доза добавки
читается как назначение, а клиент может принимать лекарства, о которых мы не знаем. Блок
состояний этого не меняет: даже зная диагноз, дозу добавки VIA-L не печатает — про добавку
остаются время приёма, пищевые источники и «дозу обсудите со специалистом».

### 9.1 Зачем блок нужен (и почему это не ломает App Store)

Спрашивать человека, что у него есть, — не диагностика. Guideline 1.4.1 запрещает приложению
**ставить** диагноз и лечить, а не принимать в анкете то, что человек и так о себе знает.
Риск лежит не на входе, а на выходе: получив «гипертония» на вход, модель поедет лечить
гипертонию. Поэтому правило: **состояние в первую очередь выключает советы, а не включает.**

Иерархия использования, в этом порядке:

1. **Вето.** Состояние снимает небезопасные для него рекомендации (§5 и §10.3). Это главная
   ценность блока — сегодня мы даём советы вслепую.
2. **Выбор паттерна и модификатора** (§3): рефлюкс → DM-REFLUX, кости → DP-CALCK2 и т. д.
3. **Нагрузка** (§10): тип, интенсивность, чего избегать.
4. **Маршрутизация**: нестабильное или неконтролируемое состояние → блок «На что обратить
   внимание» с конкретным адресатом, а не общий совет.

Чего **никогда**: не лечим состояние, не обсуждаем отмену и замену лекарств, не обещаем
изменений по диагнозу, не пишем «это поможет от вашей гипертонии». Формулировка одна:
«учитываем, что у вас есть …» + «это обсуждают с врачом».

### 9.2 Как спрашиваем

- **Каденс base** — разовый шаг первого прохода, рядом с профилем; правится в «Моём профиле».
- **Только чипы, не свободный текст.** Свободный текст не может управлять кодом (а весь смысл
  блока — детерминированные вето), плюс он же — главный источник узнаваемости записи.
- Обязательные варианты: «ничего из перечисленного» и «предпочитаю не указывать». Блок целиком
  необязательный, пропуск не блокирует разбор.
- Группы (черновик, уточнить со специалистом): сердце и сосуды · обмен (диабет 1/2, преддиабет,
  щитовидная железа) · ЖКТ (СРК, рефлюкс, целиакия, ВЗК) · почки и печень · кости и суставы
  (остеопороз/остеопения, артроз, боль в спине) · дыхание (астма/ХОБЛ, апноэ сна) ·
  гормональное (СПКЯ, эндометриоз) · онкология в анамнезе · беременность/ГВ.
- Отдельно и коротко: **«сейчас временно»** (травма, ОРВИ, восстановление после операции) —
  влияет на нагрузку и живёт неделями, а не годами; **«врач ограничил нагрузку»** (да/нет) —
  один вопрос, но он важнее половины остальных; **«состояние под контролем»** (да / нет / не знаю).
- Рядом с блоком — короткое «зачем»: чтобы не советовать лишнего; данные остаются на устройстве.

### 9.3 Приватность — что меняется

- **В исследовательский синк состояния НЕ уходят.** Диагноз + возраст + набор метрик резко
  повышают узнаваемость строки, а серверный whitelist на то и сделан, чтобы новые поля не
  попадали туда автоматически. Ничего в коде для этого делать не нужно — важно **не добавить**.
- В текст согласия (`research-consent.html`, §3 «что никогда не отправляется») дописать
  состояния здоровья — правку начинать с EN-эталона, потом 11 языков.
- В обе политики (`legal-app/privacy.html`, `legal/privacy.html`) добавить категорию «сведения о
  состояниях, которые вы указали сами» — 12 языков.
- В «Наш подход» — абзац, зачем блок и что он в первую очередь выключает советы.
- Метки App Store не меняются: Health & Fitness / App Functionality / Not Linked to You.

### 9.4 Список чипов (утверждён владельцем 2026-08-26; вето переписаны по выгрузке)

Правило отбора: **чип живёт в списке только если он что-то меняет** — снимает совет, включает
паттерн, меняет нагрузку или маршрутизирует к врачу. Всё, что «просто хорошо бы знать», из
списка выкинуто: каждый лишний чип — это лишние особо чувствительные данные и лишний экран.

Формулировка вопроса — **«что вам ставил врач»**, а не «что у вас есть»: тогда это анкета, а не

**Онкология**

|---|---|

| Чип | Что меняет |

| Чип | Что меняет |
|---|---|

| Расстройство пищевого поведения в анамнезе | **самый сильный чип: снимает граммовки, окна питания, любые ограничения и счёт** — режим без чисел о еде |

**Три вопроса вне списка** (стоят больше половины чипов):

- «Врач ограничивал вам физическую нагрузку?» — да / нет.
- «Сейчас временно»: травма · после операции · острая болезнь · обострение хронического — с датой;
  замораживает нагрузку и по истечении возвращает прогрессию с нуля.
- «Состояние под наблюдением врача?» — да / нет / не знаю. «Нет» + значимый чип → маршрут.

Плюс обязательные «ничего из этого» и «не хочу указывать»; блок необязательный, пропуск не
блокирует разбор.

**Свободный ввод «Что-то ещё» (добавлен 2026-08-26).** Человек с состоянием, которого нет в
списке, не должен уходить с ощущением, что его случай не предусмотрен. Поле идёт **только в
промпт**: вето по нему не строятся (код читает чипы, а не текст), поэтому рядом в промпте стоит
правило — не выдумывать ограничений, не строить догадок о диагнозе, при риске вреда не давать
совет и отправлять к специалисту. Лимит 200 знаков. В исследовательский синк, как и остальной
блок, не уходит. Показывать группы свёрнутыми после первого вопроса «есть ли что-то
из этого» — иначе экран пугает.

## 10. Движение под состояние и текущую форму

Сегодня секция `activity` в «Памятке дня» собирается по возрасту, полу и восстановлению. Дальше —
то же, что с едой: детерминированный слой перед моделью.

### 10.1 Вход

Возраст и фаза · текущий уровень активности и шаги · восстановление и HRV · тренд пульса покоя ·
сон · боли/скованность · риск костей · тир давления · состояния из §9 · «врач ограничил нагрузку» ·
доступное время и инвентарь.

### 10.2 Выход — недельная рамка, а не набор упражнений

Числа проставлены по выгрузке (`NUTRITION-MAPPING-EVIDENCE.md`, F19–F30).

1. **Аэробная нагрузка.** Главная фраза для новичка: **первый час в неделю даёт половину всего
   эффекта** (1 ч/нед — смертность HR 0.85, 3 ч/нед — 0.73, дальше плато). Не пугать нормой
   150–300 мин: она цель, а не вход.
2. **Силовая — 2 раза в неделю, 30–60 минут суммарно.** Это оптимум по данным, дальше прибавки нет.
   Для женщин в пери- и постменопаузе это ещё и **самый сильный немедикаментозный рычаг по приливам
   и настроению** (−50 % вазомоторных симптомов в лучшем RCT; эффект на настроение не зависит от
   того, выросла ли сила) — сильнее любого пищевого акцента.
3. **Баланс — при риске падений: ≥3 раза в неделю, минимум 12 недель, суммарно ~50 часов.**
   Отдельно предупреждать: **одна ходьба падения не предотвращает** и при нарушенном балансе может
   их участить.
4. **Мобильность и разгрузка** — под жалобу на боль.
5. **Интенсивность — разговорный тест и ощущение усилия**, и только как потолок: соответствие
   порогам умеренное, разброс между людьми широкий. На бета-блокаторах это **предпочтительный**
   инструмент, потому что пульс подавлен, а восприятие усилия сохраняется.
6. **Время суток решает мало, близость ко сну — много:** тренировка, законченная **≥4 ч до сна**,
   на сон не влияет при любой нагрузке; интенсивная за час до сна портит засыпание. Лёгкая вечерняя
   у пожилых даже сокращает засыпание.
7. **Прогрессия** — не больше ~10 % объёма в неделю.
8. **HRV — только тренд к личной базе.** Абсолютных порогов не вводить: нормативов по устройствам
   нет, ошибка носимых 20–30 %. Логика «сдвинуть тяжёлое на другой день» допустима, обещаний по
   результату не даём.
9. **Стоп-сигналы** отдельной строкой (список AHA): боль или давление в груди, в том числе отдающие
   в руку, челюсть, шею · головокружение и предобморок · обморок во время нагрузки — это экстренно ·
   перебои и учащённое сердцебиение · одышка не по нагрузке · спутанность, нарушение координации,
   бледность или синюшность · внезапное падение переносимости.

### 10.3 Вето по состояниям (переписано по выгрузке)

| Состояние | Что делаем |
|---|---|
| Давление в покое **>160/100** | откладываем интенсивную и статическую нагрузку до контроля; при субмаксимальной нагрузке систолическое ≥170 — к врачу |
| Любая силовая при высоком давлении | **главный риск — натуживание**: при закрытой голосовой щели давление доходило до 311/284, при выдохе — 198/175. Учим выдыхать на усилии, а не запрещаем силовую |
| Приём гипотензивных | удлинённая заминка (риск падения давления после нагрузки) |
| Диабетическая ретинопатия (пролиферативная) | вето на высокоинтенсивную силовую |
| Диабет на инсулине или секретагогах | вето на нагрузку натощак без врача; предупреждать о **поздней гипогликемии через 6–15 ч, риск до 48 ч**; при глюкозе >250 с кетонами не начинать; постпрандиальная нагрузка предпочтительнее |
| Остеопороз, остеопения | **не бланкетный запрет**: ограничиваем нагруженное, повторяющееся и крайнее сгибание, особенно со скручиванием; ударное — после перелома позвонка. Прописываем силовую + ударную + баланс: это работает лучше всего. Современные консенсусы прямо против общих «не сгибаться» — они порождают страх движения |
| Артроз колена или бедра | **вето снято**: низкоударное не обязательно, высокая нагрузка сустав не разрушает (START: сила сжатия не выросла). Выбираем то, что переносится и делается регулярно |
| Апноэ сна, плохое восстановление | тяжёлое переносим на другой день по тренду HRV, без абсолютных порогов |
| Врач ограничил нагрузку | никаких интервалов и прогрессии — повторяем ограничение врача |
| Беременность, ГВ | отдельный контур, по умолчанию поддерживающая нагрузка |
| Онко-лечение сейчас | щадящий режим, прогрессии нет |
| Временное (травма, ОРВИ, после операции) | нагрузка замораживается, после — возврат с нуля прогрессии |

**Сделано 2026-08-26:** `selectExercisePlan` + `buildExerciseBlock` в воркере, блок идёт следом за
пищевым. Рамку выбирает код: новичку — «первый час в неделю», втянутому — 150 минут с оговоркой,
что выше 300 прибавка исчезает; силовая 2×/нед по 30–60 минут суммарно (после 50 — как основа,
женщине в переходе — первой строкой); баланс от 3 раз в неделю и 12 недель при возрасте 60+ или
остеопорозе; интенсивность по разговорному тесту; «за 4 часа до сна» — только при жалобе на сон;
прогрессия 10 %; сегодняшняя нагрузка — по личному тренду восстановления, без абсолютных порогов.
Стоп-сигналы выдаются не каждый день, а когда есть повод (старт с нуля, сердечный сигнал,
давление вне ориентира) — иначе они превращаются в фон.

## 11. Что выгрузка изменила против черновика (сводка)

Двенадцать содержательных правок — в порядке важности:

1. **Фитоэстрогены при приливах ретированы.** Свежий мета-анализ не показал эффекта на приливы,
   лён равен плацебо. Наш дневной план сейчас вплетает молотый лён в тарелки как средство от
   приливов — это надо убрать вместе с обещанием.
2. **Соя при онкологии груди разрешена** (NCCN до 3 порций/сут, в т.ч. на тамоксифене). Вето
   переехало на концентрированные добавки изофлавонов.
3. **Силовая стала первой строкой при приливах и настроении** — там эффект сильнее, чем у любого
   пищевого акцента, и он не зависит от изменения состава тела.
4. **Цинковый паттерн для мужчин ретирован**: у не-дефицитных цинк и витамин D тестостерон не
   поднимают; работает вес и обмен.
5. **Калиевое вето сужено** до солезаменителей и добавок; фрукты-овощи при нормальных почках
   безопасны даже на ИАПФ/БРА.
6. **Вето по витамину K разделено**: варфарин — постоянство, а не избегание, добавки K2 нет;
   на DOAC ограничений нет вовсе.
7. **Почки: приложение больше ничего не ограничивает само** — только не наращивает белок и
   отправляет к врачу.
8. **Камни: пищевой кальций с едой поощряется**, оксалаты не исключаются.
9. **Рефлюкс переписан**: запретный список — традиция, работают режим, поза и объём приёма.
10. **Артроз: вето «только низкоударное» снято**; кости: бланкетное «не сгибаться» заменено на
    технику и риск-пропорциональность.
11. **Окно питания понижено** до привычки не есть поздно, без метаболических обещаний, с
    предупреждением о потере мышц; список противопоказаний расширен (язва, подагра).
12. **Железо: обещание восполнения снято** — еда даёт +9 мкг/л, причину и препарат решает врач.

Плюс числа, которых в черновике не было вовсе: порог **160/100** для интенсивной нагрузки,
натуживание как главный риск силовой, **первый час в неделю = половина эффекта**, силовая
30–60 мин/нед, баланс ≥3 раз/нед и ~50 часов суммарно, «ходьба падения не предотвращает»,
тренировка **≥4 ч до сна**, поздняя гипогликемия через 6–15 часов.
