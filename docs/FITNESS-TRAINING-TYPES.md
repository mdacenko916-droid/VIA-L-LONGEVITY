# Виды тренировок «Движения» — что каждый даёт и из каких блоков собирается

> 2026-10-08. **Зачем:** вкладка «Движение» собирает тренировку дня из коротких роликов упражнений
> (`FITNESS-APP-MODEL.md` §12): **разминка → основная часть → заминка**. Здесь — (1) какие виды тренировок
> берём и что каждый доказанно даёт женщинам и мужчинам 40+, (2) наборы блоков для каждого вида.
> Правила выбора дня — [`FITNESS-SELECTION-RULES.md`](FITNESS-SELECTION-RULES.md); виды активности вне роликов
> (ходьба, бассейн, велосипед) — [`FITNESS-ACTIVITY-SELECTION.md`](FITNESS-ACTIVITY-SELECTION.md).
> Сырьё PubMed — `interpreter/Infa Cloude/FIZ/pubmed/PM-TYPES.txt` (21 обзор, PMID сверены) + прежние файлы.
> **Уровни:** A — мета-анализы/Cochrane; B — одно-два РКИ или мета-анализ малых исследований; C — консенсус, обзор.

## 1. Главное для женщин: приливы, сон, память, концентрация

| Что беспокоит | Сильнее всего помогает | Цифры | Ур. |
|---|---|---|---|

**Вывод для женщин.** Ваша мысль верна: **силовые — центр**: приливы, сон, общая ясность ума, настроение, кости.
Но **для памяти нужны аэробные**, а **для внимания и сна — йога/пилатес/тайцзи**. Поэтому неделя — это силовые
2–3 раза + аэробное (вне роликов: ходьба, бассейн, велосипед) + один день тело-разум.

## 2. Главное для мужчин 40+

| Что беспокоит | Что помогает | Цифры | Ур. |
|---|---|---|---|
| Сила, мышцы, вес, живот | силовые 2–3 раза; HIIT/аэробные для жира | см. `FITNESS-MEN-EVIDENCE.md` | A |
| «Низкий тестостерон», энергия | тренировки — ради силы и самочувствия; **базовый тестостерон силовые не поднимают** | там же; лучший рычаг при лишнем весе — снижение веса | A |
| **Эрекция** | **аэробные умеренно-интенсивные** | IIEF +3,85 (мета-анализ 7 РКИ, 27707739) | B |
| Сон, память, внимание, настроение | то же, что у женщин: пол в мета-анализах эффект не меняет | 28438770; 40049759; 29800984 | A |
| Кости | силовые + удар (~50 прыжков) | см. `FITNESS-MEN-EVIDENCE.md` | B |
| Подтекание после операции на простате | ⚠️ **тренировка тазового дна НЕ лучше наблюдения** в первые 12 мес (Cochrane 2015, 8 РКИ, 25602133) | у мужчин симптомы проходят со временем у всех | A |

**⚠️ Поправка в `FITNESS-MEN-EVIDENCE.md`:** строка «помогает после операции на простате» Cochrane не подтверждает —
тазовое дно у мужчин оставляем, но **без обещания** «поможет после операции».

|---|---|---|---|---|

Аэробное (ходьба, бассейн, велосипед, танцы) — не ролики, а виды активности: их подбирает
`FITNESS-ACTIVITY-SELECTION.md`, и они засчитываются в неделю.

## 4. Разминка и заминка — что доказано

- **Разминка нужна:** улучшает выполнение в 79% показателей (мета-анализ, 19996770); травмы — данных мало, но
  перевес в пользу разминки (16679062). → **5–8 мин, динамическая, под зону дня**, без долгой статической растяжки.
- **Заминка — не «от крепатуры»:** активная заминка почти не ускоряет восстановление (29663142); растяжка до
  или после не уменьшает крепатуру — полбалла из 100 (Cochrane, 21735398). Зато заминка **плавно возвращает
  пульс и дыхание** — для наших 40+ (давление, головокружение после нагрузки) это довод сам по себе (C).
  → **3–5 мин:** спокойная ходьба на месте, дыхание с длинным выдохом, мягкая подвижность. Статическая растяжка —
  по желанию, ради гибкости, а не «чтобы не болело».

## 5. Наборы блоков (из `FITNESS-EXERCISE-LIST.md`)

Каждое упражнение — ролик 10–15 с; у базовых есть облегчённый и усложнённый вариант (→ кнопки «легче /
тяжелее»). Код берёт **разминку 3–4 · основную 4–5 · заминку 2–3** по виду, зоне, уровню и ограничениям.

### 5.1 Разминка — по зоне дня

| Зона дня | Упражнения разминки |
|---|---|
| Ноги / всё тело | шаг на месте с махами рук → круги тазом → полуприсед → наклон с прямой спиной без веса |
| Верх | шаг на месте с махами рук → кошка-корова → отжимания от стены (лёгко) → «птица-собака» |
| Корпус и тазовое дно | дыхание с длинным выдохом → мост с дыханием → кошка-корова → сокращение тазового дна при подъёме со стула |
| Баланс | шаг на месте → круги тазом → стойка на одной ноге у опоры |

### 5.2 Основная часть — пулы по виду и уровню (облегчённый → базовый → усложнённый)

**Сила: ноги и ягодицы** — присед к стулу → гоблет-присед → присед с двумя гантелями; наклон с прямой спиной →
румынская тяга с гантелями → на одной ноге; ягодичный мост → мост на одной ноге → с плечами на стуле;
выпад назад (с опорой → без → в сторону); подъём на ступеньку; подъём на носки.
*Прыжки внутри (не при запретах, §6 правил):* мини-прыжки на месте → из стороны в сторону → из неглубокого приседа.

**Сила: верх** — отжимания от стены → от стола → с колен → от пола; тяга гантели в наклоне с опорой → двух гантелей;
жим над головой сидя → стоя → одной рукой; жим лёжа на полу; разведение рук в наклоне; «прогулка фермера» →
«чемоданная прогулка».

**Сила: всё тело** — по 1–2 из ног и верха + присед с жимом над головой, «прогулка фермера».

**Корпус и тазовое дно** — «мёртвый жук» → касание пятками пола; планка на предплечьях → на прямых руках →
с касанием плеча; боковая планка с колен → на предплечье; «птица-собака»; «лодочка»; мост с дыханием;
сокращение тазового дна при подъёме со стула (упреждающее сокращение).

**Баланс и ловкость** — стойка на одной ноге (у опоры → без → с закрытыми глазами); ходьба пятка к носку;
«часы»; шаги в стороны с перешагиванием; реакция с ловлей мяча. **Двойная задача:** то же + счёт обратно
через 3 / называть слова на букву (для памяти и внимания).

**Мобильность** — круги тазом, кошка-корова, шаг на месте с махами рук, растяжка передней и задней поверхности бедра.

**Пилатес и тело-разум** — ⚠️ **в списке упражнений их пока нет**: нужно добавить пул (дыхание, «сотня»,
скручивание позвоночника лёжа, «кошка» с дыханием, медленные переходы стоя) — задача для Марины и для съёмки.

**HIIT (тренированный)** — 2–3 раунда коротких интервалов из: присед с жимом, «джампинг джек», прыжки из
стороны в сторону, быстрая «прогулка фермера»; между раундами — шаг на месте.

### 5.3 Заминка

Шаг на месте медленно → дыхание с длинным выдохом → кошка-корова или растяжка бедра (по зоне дня).

## 6. Пробелы

1. **Пилатес и тело-разум** — нет упражнений в библиотеке → дополнить список и задания на съёмку.
2. **Тайцзи** — Марина не добавила в виды активности, но для внимания и сна у него сильные данные; можно взять
   медленные движения тайцзи **внутрь тела-разума**, не отдельным видом — на решение Марины.
3. Двойная задача — в упражнениях сейчас нет голосовой подсказки «считайте обратно» — для роликов баланса.
4. Мужской трек: пул упражнений — свой (`FITNESS-MEN-EVIDENCE.md` §3); блоки собираются так же.
