# «Напоминания на сегодня» — пул из 100 напоминаний (✅ в коде 2026-11-10: `interpreter/day-tasks.js`)

Идея Марины: вместо длинной памятки — короткие напоминания вроде «выпейте сегодня 2 литра воды»,
«после еды 5–15 минут двигайтесь». Пул собран из того, что в VIA-L уже проверено и вычитано:
рычаги «Фокуса недели» (`interpreter/levers.js`), курсы «День 1–7» (`interpreter/courses.js`),
таблица «что беспокоит → что делать» (`docs/DAYPLAN-COMPLAINT-TABLE.md`), главы памятки дня,
паттерны базы знаний воркера (`[P-F…]`, `[P-M…]` в `interpreter/cloudflare-worker.js`) и
`docs/BLOOD-PRESSURE-EVIDENCE.md`. Новых медицинских утверждений здесь нет — только перевод уже
принятого в одно действие.

## Как это работает — решение владельца 2026-11-10

- **В памятке на день — только 2 напоминания** из пула, без кнопок «Сделано» / «Позже» и без галочек:
  просто две строки сверху памятки. Выбирает код (не ИИ): одно — по шагу «Фокуса недели» или главной
  жалобе, второе — бытовое (вода, движение, еда, вечер). Одно и то же не повторяется чаще раза в 3 дня.
  Учитываются вчерашние данные (плохая ночь → «силовую вдвое меньше», жаркая ночь → «прохлада»;
  нет трекера → без дел про шаги).
- **Утренний пуш зовёт сделать проход**, а не пересказывает памятку: «Минута на отметки — и разбор на
  сегодня готов» (3 формулировки ×12, сменяются по дню). ✅ сделано 2026-11-10 в VIA-L (`_ntText`, `NT_PASS`).
  Нажатие: проход сегодня не сделан → ежедневный экран с проходом; сделан → «Памятка дня» (`notify-bridge.js`).
- Пометка **пуш** в списке ниже пока не используется (пуш один — о проходе); оставлена на случай, если
  позже включим второй пуш с напоминанием.
- `{…}` — подставляет код из данных человека (литраж по массе тела и белок на приём уже
  считаются в памятке; время ужина — от обычного времени сна).
- **Памятка = только это (владелец 2026-11-10, второе слово):** блок «Напоминания на сегодня» (2 строки) +
  карточка прохода. Проход не сделан — «Как вы сегодня? Отметьте ночь и самочувствие — и получите разбор
  на сегодня. Займёт минуту.» + кнопка **«Начать»**; сделан — **только два напоминания**, без карточки
  («Разбор готов / Открыть разбор» убрано владельцем: напоминать о сделанном — только раздражать).
  Прежний блок (тарелка, принцип VIA·L, главы с меню, «Что беспокоит», «Приём сегодня») **не показывается**.
  Пуш ведёт в эту памятку. Макет — скрин в чате 2026-11-10.
- ⚠️ Вместе с этим поправить обещания «памятка дня с меню» ×12: пэйволл в `interpreter-via-l.html`
  (4 места) и «Что нового»/описания сторов при следующей версии — иначе за подписку обещано то, чего нет.
- Формулировка: «после приёма пищи / после еды», а не «после обеда» (владелец).

## Правила текста (как в таблице жалоб)

Без доз добавок, без «лечит / нормализует», без диагнозов. Граммы белка, литры воды и минуты
ходьбы называть можно. Одно действие — одна строка. На «вы», тепло, без давления.

Обозначения: **когда** — утро / еда / день / вечер / ночь / неделя; **кому** — все / ж / м;
**жалобы** — ключи «С чем вы пришли»: sleep сон, hf приливы, energy энергия, mood настроение,
fog туман, weight вес, pain боли, muscle мышцы, drive драйв, libido близость, cycle цикл,
bp давление, gut кишечник, bone кости; **рычаг** — ключ levers.js.
