# Поиск первой тренерки (Украина) — рабочий файл

> Начато 2026-09-14. Модель — `docs/FITNESS-APP-MODEL.md` (§3 паттерны, §6 каталог, §7.7 оплата, §10.5a дубляж).
> Цель первого этапа: 3–5 кандидаток → разговор → пробное видео → узнать цену и условия.

## 1. Кого ищем

**Обязательно**
- Женщина, **ориентир 40–55** (лучше 40–50; мужской трек — 40–55): лично проходит этап — доверие аудитории.
  ⚠️ В объявлениях возраст **не писать требованием** (дискриминация по возрасту, UA/ЕС) — формулировка
  «сам проходить етап 40+ і розуміє його»; возраст спрашивать в отклике. Форма для HIIT/прыжков — по пробному видео.
- Родной язык украинский, уверенно ведёт занятие голосом без бумажки.
- Профессиональная база — одно из:
  - фізична терапевтка / реабілітологиня (диплом) с опытом тазового дна;
  - тренерка с профильным сертификатом по менопаузе, например: Girls Gone Strong Menopause Coaching
    Specialist, The Center for Women's Fitness (Menopause / Pilates for Menopause), Menopause Movement
    (CIMSPA), NETA Menopause Specialty;
  - инструкторка пилатеса / силовых с многолетней практикой именно с женщинами 40+ (подтверждаемой).
- Умеет давать модификации на ходу («якщо болить коліно — …»).

**Плюс**
- Работает и с силовой, и с мобильностью/пилатесом (закрывает несколько типов из 5).
- Спокойная, тёплая подача без «спалимо жир до літа».
- Есть снятые занятия / эфиры — видно, как держится в кадре.
- Готова на ИИ-дубляж своим голосом (§10.5a).

**Нет**
- Только эстетика тела и марафоны похудения; обещания лечения; нет подтверждения квалификации.

## 5. Пробное задание (10 мин видео)
- Фрагмент **силовой тренировки, уровень «старт»**, для женщины в перименопаузе: разминка 2–3 мин +
  3–4 упражнения основной части.
- Голосом в кадре, как на реальном занятии; ведущая **одна в кадре** и сама показывает облегчённый вариант
  хотя бы в двух упражнениях, называя, кому он нужен.
- В начале — 30 с стоп-сигналов своими словами (біль у грудях, запаморочення, перебої, задишка не за навантаженням).
- Снять на телефон горизонтально, звук с петлички, без музыки (музыку наложим отдельно — для дубляжа).
- Смотрим: подача, модификации, безопасность, звук, «веришь ли ей».

## 6. Что узнать о цене и правах
- Сколько стоит её время на **1 готовое 30-мин занятие** (подготовка + репетиция + съёмка).
- Сколько за **набор из 14**; есть ли своё оборудование / место для съёмки; нужна ли помощь со съёмкой.
- Какой вариант прав ей ближе: **выкуп навсегда** / **лицензия + процент с просмотров** / аванс в счёт процента.
- Согласие на **ИИ-клон голоса и переводы** на другие языки.
- Эксклюзивность: не публиковать эти же занятия в других приложениях.
- Юр. форма (ФОП?) — как ей платить.

## 6b. Вариант «исполнительница по нашему плану» (идея владельца 2026-09-14)

озвучивают **наш** план тренировки по требованиям съёмки.

- **Автор программ — мы**, значит права проще: разовый выкуп у исполнительницы (образ, голос, переводы, дубляж).
- **Решение владельца 2026-09-14: методиста нет.** Это обычные ежедневные тренировки для простых людей,

  путь — чистовая озвучка после съёмки (для дубляжа всё равно нужен чистый голос).

## 6c. Как платить — две модели (оценки, сверить разговорами)

**Модель 1 — разово, выкуп всех прав.** Подходит исполнительницам (6b).
- Исполнительница: подготовка + репетиция + съёмка ≈ 2,5 ч на ролик × 14 ≈ 35 ч, ставка условно
  400–600 грн/ч → 14–21 тыс. грн + надбавка за образ и голос по всему миру (+50–100%) →
  **≈ 25–40 тыс. грн (€550–850)**.
- Планы пишет Claude — отдельной оплаты нет.
- Дальше платить нечего. Всё наше, любые языки и дубляж.

**Модель 2 — разово меньше + процент с просмотров.** Подходит авторам-тренерам (их имя и программы
приводят зрителей).
- Фикс ≈ половина модели 1 для тренера (набор €2000–3000 → **€1000–1500**).
- Плюс доля фонда тренеров по минутам просмотра (`FITNESS-APP-MODEL.md` §7.7) — пока ролики в приложении
  и N лет после ухода.
- Тренер рискует вместе с нами: мало зрителей — мало денег, много — больше, чем при выкупе.
- **Сколько за одну тренировку (условно):** фонд ≈ €3,4 с платящего клиента в месяц (20% от ≈ €17 чистыми,
  §7.7). Клиент делает ~12–17 тренировок по 30 мин → **≈ €0,20–0,30 за одну досмотренную тренировку**;
  если занимается только половина платящих — **≈ €0,40–0,55**. Досмотрел половину — половина суммы.
  Пример: 100 активных клиентов × 12 тренировок = 1200 просмотров/мес → **≈ €240–600/мес**.
  Фикс модели 1 (€2500) в просмотрах ≈ 5–12 тыс. досмотренных тренировок.

**Решение владельца 2026-09-14:** выкупа для настоящих тренеров НЕ будет (нет €20–30 тыс.) — с тренерами
только **модель 2** (аванс €1000–1500 + 30% чистой выручки в фонд по минутам). Модель 1 — только для
непубличных исполнительниц.

**Расчёт на 10 тренеров** (микс планов 40% месяц / 35% квартал / 25% год → в фонд ≈ €2,40 с платящего/мес;
занимаются 70% платящих по 12 тренировок): 100 клиентов — фонд €240/мес, тренеру €24, нам ≈ €554;
500 — €1200, тренеру €120, нам ≈ €2770; 1000 — €2400, тренеру €240, нам ≈ €5540 (до наших расходов:
реклама, разработка, серверы, налоги, возврат авансов). Популярный тренер ≈ 25% минут, слабый ≈ 3%.

**Решение владельца 2026-09-14 (пересмотр): основная модель — открытый кличь по миру + разовый выкуп.**
- **$500 за пакет 14 видео** по НАШЕМУ плану и инструкции; процентов нет, все права наши.
- Отбор: требования + **пробное видео 10 мин** → присылают → смотрим → договор. Не решаем за людей,
  кто «достоин»: решает проба.
- Модель 2 (аванс + процент) — только если придёт сильный публичный тренер и сам этого захочет.

Что учесть при $500:
- ≈ $36 за готовое 30-мин видео, ≈ 35 ч работы → ≈ $14/ч: нормально для Украины и стран с похожими
  ставками, мало для ЕС/США — откликнутся в основном оттуда; с дубляжом это не мешает.
- **Оплата частями по приёмке:** например $100 после первых 2 принятых роликов, $400 после всех 14.
- **Договор выкупа:** образ, голос, клон голоса и переводы, весь мир, бессрочно, без процентов.
- **Оборудование и место — их;** щадящий вариант показывает сама ведущая (без второй участницы), чтобы
  не удорожать.
- **Выплаты за границу** — через договор и платёжный сервис; упирается в ФОП (вопрос юристу).
