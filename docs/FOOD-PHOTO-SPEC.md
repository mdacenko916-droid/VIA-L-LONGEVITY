## ЕДИНЫЕ ТРЕБОВАНИЯ КО ВСЕМ ФОТО (вставлять в каждый промпт)

| Параметр | Значение |
|---|---|
| Размер | **1024×1024 px, квадрат** (родной для gpt-image) |
| Фон | **Прозрачный (PNG)**, без стола/скатерти/приборов/салфеток/декора |
| Тень | Мягкая полупрозрачная контактная тень ПОД тарелкой (даёт «посадку» на тёмном фоне) |
| Ракурс | **45° три четверти** (как смотришь на тарелку, сидя за столом) — видно и раскладку, и высоту еды |
| Тарелка | **Одна и та же на ВСЕХ фото:** круглая матовая керамика тёмно-графитового цвета, без рисунка; тарелка занимает ~85% кадра, по центру |
| Свет | Тёплый боковой свет сверху-слева (золотистый, «вечерний ресторанный»), одинаковый на всех фото |
| Стиль | Фотореализм, ЧЕСТНАЯ домашняя порция по граммовке (не ресторанная башня, без излишнего гарнира/соусов-разводов) |
| Имя файла | Ключ блюда: `bf_eggs_veg.png` и т.д. |

**Шаблон промпта (EN для gpt-image, подставить [СОСТАВ]):**
"Photorealistic food photography, single round matte dark-graphite ceramic plate centered, filling ~85% of frame, 45-degree three-quarter view, warm golden side lighting from upper left, soft translucent contact shadow under the plate, transparent background, no table, no cutlery, no napkins, honest realistic home portion sizes: [СОСТАВ]. 1024x1024, PNG with transparency."

## Что дальше (после получения фото)
1. Фото → я конвертирую в webp (~600px, <60 КБ), кладу в `interpreter/food/`.
2. Воркер `/day-plan`: инструкция выбирать варианты еды из каталога + помечать `[dish:KEY]` в конце пункта (клиент вырезает метку из текста).
3. Клиентский рендер варианта: фото + название + состав + «≈ Б/Ж/У» (как в макете владельца «скрин/2.jpg»).
4. Фолбэк: вариант без метки/фото рендерится текстом, как сейчас. Старые кэши дня не трогаем.
